WHAT WAS BUILT
- The PTY-level marks come from T-104-b (shell_marks.rs wrappers print OSC 133;A at each prompt, 133;C at a command
  start, 133;D;<exit> at its end; src/terminal/shellMarks.ts parses them split-safely from the raw output bytes, with
  OSC 0/2 titles, BEL and ST terminators). This card wires the pane and the tab strip to them:
- evidence/sessions-T-119-c-TerminalPane.tsx.patch (core-owned file): the terminal-output draw path feeds the Scanner
  from the decoded bytes before xterm sees them (never from the restored-history replay, which writes to xterm
  directly, so replayed titles never count); each mark runs reduceIdentity (start -> running; title -> program title
  and the agent it names, claude/codex; prompt or end mark -> idle, agent forgotten); the Gate holds pre-prompt output
  for wrapped shells (printsMarks(shellName)) until the first prompt mark, the 4 s READY_WAIT_MS, the exit, a
  reattached terminal after a reload, or a fallback shell without hooks (ACCT-046); the Startup object replaces the
  SESS-051 quiet timer: the typed-route command goes in once at the first prompt mark (bracketed paste for long or
  quoted text), the quiet timer stays only for shells without hooks, and a shell that ends before the command went
  still reports the failed launch (VIEW-069). Header icon and data-agent: hook-reported agent (pane-agent) beats the
  title guess, else shownAgent (title agent while a command runs; plain shell at the prompt). Pane title:
  followedTitle (job title > running program's title > folder > Terminal N); a path-only title is not a program's.
  Held bytes are acknowledged to the flow control when taken, so holding never stalls the PTY reader. Timers are
  cleared on unmount. New prop onIdentity reports the live identity upward.
- evidence/sessions-T-119-c-App.tsx.patch (shared file): liveIds state per pane fed by onIdentity; the tab's
  VendorMark icon = shownAgent(p.agent, live); tabName takes the live identity (followedTitle, user's own name wins);
  only the two tab-strip call sites pass it (menus, toasts and the Inbox keep the stable name).
- Each tab holds one pane today, so the tab's icon is its own pane's; tabAgent (focused pane only, tested) is ready
  for a tab that holds a split and is otherwise unused.

DECISIONS (defaults taken)
- D5: the title counts as the program's only while a command runs (between 133;C and the next 133;A/D), as TERM-058
  says; a shell's own prompt title (the cwd) therefore never renames the tab. PowerShell prints no 133;C (D4), so
  there a title that names an agent is what marks a running program.
- D6: the tab strip, not menus or notifications, follows the live title; the rest keeps the stable automatic name so
  the Inbox and toasts do not rename mid-sentence.
