- New src-tauri/src/agent_hooks/vendors.rs: normalize() turns each vendor's event into the shape the
  status rules read; change() is Codex's mapping plus Antigravity's ask tools (ask_question,
  ask_permission) reading Waiting; install / remove / inspect per vendor; the Amp plugin text.
  - Gemini CLI: ~/.gemini/settings.json, one Kolux group under BeforeAgent, AfterAgent, BeforeTool,
    AfterTool (matcher "*" on the tool events, timeout 10000 ms); the user's hooks stay.
    BeforeAgent=Working(prompt), BeforeTool/AfterTool=Working, AfterAgent=Done (reply = prompt_response).
  - Antigravity: ~/.gemini/config/hooks.json, bundle "kolux-rs", one command per event with the event
    name as its argument (the payload has none); a same-named bundle of the user's is refused.
    PreInvocation=Working, PreToolUse=Working (ask tools: Waiting), PostToolUse/PostInvocation=Working,
    Stop=Done only when fullyIdle is true. Kolux answers PreToolUse {"decision":"allow"}.
  - Amp: ~/.config/amp/plugins/kolux-rs.js ("Written by Kolux RS"); never put over a user file, removal
    deletes only Kolux's own. agent.start=Working, tool.call/tool.result=Working, agent.end=Done, or
    Interrupted when its status is not "done". It spools to the hold file when Kolux is closed.

  reads Interrupted. hooks.rs: /gemini, /amp, /antigravity/<Event> routes; install_groups takes the

LIVE PROOF PENDING (batched; NO APP LAUNCHES rule 2026-10-13)
Dev build, scratch homes, status hooks switch on (Settings > Agents). Open a plain shell pane P.
In P (cmd), first run: set S=%USERPROFILE%\.kolux-rs\agent-hooks:
1. echo {"hook_event_name":"BeforeAgent","prompt":"proof"} | "%S%\gemini.cmd"
   -> P's status dot reads Working; the Board card shows the prompt "proof"; the script prints {}.
2. echo {"hook_event_name":"AfterAgent","prompt_response":"All done"} | "%S%\gemini.cmd"
   -> dot reads Done; the card's reply reads "All done".
3. echo {"conversationId":"c1"} | "%S%\antigravity.cmd" PreInvocation  -> Working.
4. echo {"toolCall":{"name":"ask_question","args":{}}} | "%S%\antigravity.cmd" PreToolUse
   -> dot reads Waiting; the script prints {"decision":"allow"}.
5. echo {"fullyIdle":false} | "%S%\antigravity.cmd" Stop -> stays Waiting/Working (no change);
   echo {"fullyIdle":true} | "%S%\antigravity.cmd" Stop -> Done.
6. Amp (plugin under %USERPROFILE%\.config\amp\plugins\kolux-rs.js, written by the switch when amp is
   found): in P run node with a stand-in host:
   node --input-type=module -e "const m=await import('file:///'+process.env.USERPROFILE.replace(/\\/g,'/')+'/.config/amp/plugins/kolux-rs.js');const h={};m.default({on:(n,f)=>h[n]=f});await h['agent.start']({message:'go',thread:{id:'t'}});await new Promise(r=>setTimeout(r,1500));await h['agent.end']({status:'cancelled',thread:{id:'t'}})"
   -> Working, then Interrupted (the Board card reads Stopped).
7. `kolux-rs agent hooks status` (scratch env) lists Gemini CLI, Antigravity and Amp rows with their files.
