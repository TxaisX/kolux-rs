T-067-b · USAGE-011 rest (from T-136-d): a lost connection that owned a pane ends that pane's open turn in the activity counts
Lane core, built on 70641130 (T-153-f), Opus builder, 2026-10-20. Text proof (no visible-UI screenshot under Routing v3).

What the connection is
- With the background terminal service (T-075-b / T-184-b), a pane's terminal belongs to the window's link to the service. When that connection is lost (the service crashed or was ended, or the loopback socket broke), Link::close_all runs every carried pane's exit with no code (Ev::Exit(None)); a pane registered after the loss gets the same end at its flush.

What was built
- src-tauri/src/terminal.rs: turns_end(id), the one end every terminal exit goes through, local or carried by the service, including the lost connection: activity::terminal_ended first (the turn of each pane the terminal's hooks reported for ends, and the terminal is retired for those panes), then status::terminal_ended (TERM-122: the panes' sessions go, the terminal is remembered as ended). The exit handler now calls it instead of the two calls inline.
- src-tauri/src/pty_link.rs (tests): losable_link(ids), a stand-in service that carries the given terminals and drops the connection on demand.
- Test (shared file, so as a patch): evidence/core-T-067-b-activity.rs.patch adds activity::tests::t067b_a_lost_service_connection_ends_the_open_turn_of_each_pane_it_carried_once.

Card rules (USAGE-011)
- Losing the connection that owned a pane ends any session (turn) it had open: the test opens a turn on a pane through a real hook report, drops the connection, and the turn and the pane's lane end with no code.
- Exactly once, and a status repeated after a reconnect never starts another: the end ran once; the same UserPromptSubmit from the same terminal afterwards is dropped (no turn, no reopened lane, no status session).
- A pane the connection did not carry keeps its open turn.
- Closing a pane, a terminal exit and the quit already ended the turn (T-136-d, T-260-c, take_save at quit); unchanged.
