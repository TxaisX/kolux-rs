LIVE PROOF PENDING (batched; run by the proof lane, never by a builder)
Set-up: a worktree W with a browser tab open on a page that sets cookies (any local dev page), a
second worktree V with its own tab, a folder with index.html + css/a.css in W. CLI = the built
kolux-dev with the four T-241 patches merged.
1. tab list: from a terminal in W `kolux-dev tab list` shows W's tab(s) with * on the one on
   screen, title and address; `--worktree all` shows V's too; `--show-profile` adds "profile
   default"; `--json` prints {tabs:[...]}.
2. tab create / switch / close: `kolux-dev tab create --url https://example.com` opens a tab in the
   focused split and prints its page number within a second; `kolux-dev tab switch --index <n>` of
   the first tab brings it on screen (the new one hides); `kolux-dev tab close --index <new>` closes
   it and the answer carries destructive: true; `tab create --url kolux-chord:x` is refused like
   the address bar refuses it, nothing opens.
3. preview: `kolux-dev tab create --url <W>/site/index.html` opens a tab whose bar shows
   "<folder> / index.html" with a copy button instead of an address; the page is styled by css/a.css
   (the stylesheet loads from the loopback port); in the page, fetch('../x') answers 403/404, never a
   file outside the folder; copy puts the file's full path on the clipboard.
4. profiles: `kolux-dev profiles list` shows default; `profiles create --label Work` answers id
   work; `tab create --url https://example.com --profile work` opens a tab that has no cookies of
   the default (sign in on one, the other stays signed out); `tab profile` on it says work; `tab
   profile set --profile default` answers "from its next open"; `profiles delete --profile default`
   is refused; `profiles delete --profile work` answers destructive: true and `tab profile` on the
   tab says default. <app data>/browser-profiles.json holds the rows; <app data>/browser-profiles/
   work holds the engine data.
5. cookies and storage: on the dev page `kolux-dev cookie set --name k --value v`, then `cookie
   get` lists k=v (and only cookies the page can read); `cookie get --url https://other.test` is
   refused (--url must be the page's site); `cookie set --name a --value 1 --httpOnly` answers code
   unsupported; `cookie delete --name k` answers destructive: true and `cookie get --name k` is
   empty. `storage set --area local --key a --value 1`, `storage get --area local --key a` prints 1,
   `storage get --area local` prints the whole object, `storage clear --area local` answers
   destructive: true and the page's localStorage is empty (devtools or `eval --expression
   localStorage.length` = 0).
6. help: `kolux-dev help tab`, `help tab profile`, `help profiles`, `help cookie`, `help storage`,
   `kolux-dev storage set --help` each exit 0 and show the lines; `kolux-dev agent-context` lists tab
   list with a summary.
