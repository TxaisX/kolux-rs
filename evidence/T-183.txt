  APP-049  prepare_state(dir, scratch): zero-byte state.db (and -wal/-shm) = missing, removed, nothing set aside; health() opens the

  APP-021  startup_check(install, profile, user, own, icacls): writable() probe file in the profile folder; unreadable_files() opens
           every file in the install folder and its resources/ folder (DirEntry::file_type, since metadata is denied too) and lists
           PermissionDenied ones; own_install() = exe folder under LOCALAPPDATA or USERPROFILE; repair() runs icacls /reset, then
           /remove:d <user>, then /grant <user>:(F) (CREATE_NO_WINDOW), mildest first, stopping as soon as the file reads; install
           files are repaired only on a per-user install, the profile folder always. PermReport::problem() is the sentence the
           APP-042 prompt names. graphics_crash_noted() with unreadable install files logs a permissions problem and never counts a
           GPU crash.
  APP-042  Interface state machine fed by a heartbeat (ui_heartbeat command, every 2 s from RecoveryMount) and ticked every second by
           the watch thread (watch_start): first load gets 90 s, afterwards 20 s without a beat = Reload{1}; 20 s more = Reload{2};
           20 s more = Prompt(Stalled). Recoveries are counted in a 10-minute window; the 4th asks (Prompt(Loop)) instead of
           reloading (circuit breaker). A tick gap >= 10 s (sleep) restarts the budget instead of counting as a stall. While the
           prompt is up or after Quit nothing else fires (prompts never stack); the thread skips every tick while the main window is
           gone (closing or not yet up), so no prompt shows for a closing window. The prompt is a native MessageBoxW
           MB_RETRYCANCEL: Retry = reload, Cancel = app.exit(0); its text names what happened, the likely cause (the APP-021
           permissions sentence when there is one, a graphics hint, or a plain "stalled while loading"), and two commands to copy
           (icacls reset of the install folder; WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--disable-gpu). Each prompt also leaves an
           APP-039 crash record. An error page sends no heartbeat, so it is never counted as success. ScreenBoundary (src/recovery)
           catches render errors with Try again (remount) and Reload.
  APP-043  Burst: 3 webglcontextlost reports inside 60 s fire once per session; graphics_crash_noted() saves safe-graphics.json
           {version, chosen:false} BEFORE the user answers and returns true; RecoveryMount offers Restart in safe graphics
           (graphics_restart_safe -> app.restart()) or Keep Running (graphics_keep_running removes the flag). run(): safe_graphics_on
           (flag present, same app version, Windows) puts `--disable-gpu` into every window's additional_browser_args, keeping wry's
           own default arguments (safe_args never adds it twice). launch_flag drops a flag from another version; off Windows the
           flag is ignored (kept). A recovered launch with chosen=false asks Stay in safe graphics (preselected) / Try hardware
           again (graphics_choose: stay writes chosen=true and asks no more; try removes the flag and restarts).
  APP-039  startup_scan(): the previous run is the log text between the last two `kolux-rs: config:` lines (newest rotated log
           prepended); no `app exit` / `could not start:` line = crash; summary = the `fatal error` line without its time stamp, else
