T-273 · PROJ-087 Claude finds each workspace's history on Windows
lane/sessions from 0819c57, 2026-10-13

Rule built (src-tauri/src/sessions.rs, new module): the folder key is the workspace path as the
system reported it, long-path prefix dropped, backslashes turned into forward slashes, the drive
letter's case untouched, no trailing slash; Claude's history folder name is that key with every
character that is not an ASCII letter or digit turned into "-". The exact folder is used when it
exists, else the folder whose name matches ignoring case (a drive letter reported the other way
round, or a case-sensitive disk). claude_sessions lists that folder's top-level .jsonl
transcripts newest first (sub-folder subagent files belong to their parent); no projects folder or
no history folder is an empty list. Tauri command: claude_workspace_sessions(workspace).
