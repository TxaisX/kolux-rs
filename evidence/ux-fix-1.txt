ux fix 1: a relaunch keeps every pane, empty choosers included (lane ux, 2026-10-25)

Root cause: layoutOf (src/terminal/layout.ts) skipped every never-started chooser pane when the layout was
written ("a chooser that was never started is no tab yet"), so 9 panes (4 shells + 5 choosers) came back as 4.
Not documented as intended: spec PROJ-067 says every workspace returns with its tabs and layout; DT-R34 only says
a restored workspace is not re-seeded. MERGE 278 "card 723" was about the save ORDER of panes, not choosers.
Second finding: probeGpu() (src/terminal/inputWire.ts), called by every pane mount at TerminalPane.tsx:590,
made a throwaway WebGL2 canvas context each time and never gave it back; browsers cap live contexts at 16 and warn
"Too many active WebGL contexts" (dev StrictMode mounts each pane twice).
