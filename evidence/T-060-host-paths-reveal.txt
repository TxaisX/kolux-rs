every refusal above answered in 2-3 ms because the check reads the text and never touches the filesystem.

== the rules themselves ==
links::tests::safe021_* checks fourteen host forms (double backslash and double slash, file URLs naming a host,
`file:////`, a percent-encoded share inside a file URL, `\\?\UNC` and `\\.\UNC`, a device pipe, a volume, three
`..` climbs including one from a WSL root), fifteen local forms (drives, POSIX paths, WSL roots in all four
spellings and as file URLs, long-path drives, `file://localhost`), registered shares (under a UNC project root in
short and long form, case folded; a sibling, a climb out of it and a local root never exempting a share), and that
the refusal of a host that cannot exist answers in under half a second with the "another computer" message.
safe022_* checks 23 program types on both platforms, the Windows disguises (stream suffix, `:$DATA`, trailing dots
and spaces, `PROGRA~1.EXE`, `notes~1.txt`), ten documents, and the POSIX reading of colons, tildes and backslashes;
safe022_the_execute_bit_counts_on_posix runs on Unix only. cargo test --lib safe02: 2 passed (Windows).
