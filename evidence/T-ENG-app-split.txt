== How it was moved (code moved, logic not rewritten)
- Every block was cut from App.tsx as whole statements and pasted unchanged into a hook (or a plain
  function where the block held no hook), called at the line where the block sat. The import lists,
  the inputs of each hook and its destructurings were generated from the TypeScript checker (symbol
  resolution), not written by hand.
- The action closures (launch, pane/tab, review) moved into three factories called once per render,
  as the closures were made once per render. 24 references inside them name a value the window makes
  later in its render (a later hook or ref: pendingLineup, setupExits, cli, startSetup, projectOf,
  select, exitedPrompt, guard, setReveal, panesRef); those read `late.<name>` from the window's
  per-render object, filled before the window draws (shell/windowLate.ts, ponytail note there). That
  is the only text change inside moved code, apart from `export` on tabName/TabBadge/StartLine, and
  one destructuring line at the top of each of the two key effects (keys/useWindowKeys.ts), which read
  the same object when they run.
- Check that every original line survives: every non-blank line of the original Window body is
  found verbatim in the new files except 27 lines, which are exactly the late.<name> rewrites, the
  three `export` additions and the split of two hook results into an object plus a destructuring.
