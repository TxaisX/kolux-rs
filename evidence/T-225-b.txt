What the user gets
- Source Control keeps showing the last good status when an automatic refresh fails, and an older
  status answer never overwrites a newer one (a ticket guard around load and the watch callback).
- The main button follows the newer VIEW-065 rules: a branch that differs from its remote only by
  equivalent patches reads Create pull request (Force push stays in the commit menu); a detached
  HEAD never offers Publish and offers Create pull request when a compare base is known.
- While merge conflicts are unresolved or an operation is in progress the message box is disabled
  with the reason as its tooltip.
- A failed commit shows a one-line summary (a lint-step failure is named as one, with its problem
  count) and the full output only when it says more.
