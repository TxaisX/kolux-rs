(c) A4/A5: the Gemini CLI hook command quotes every single quote PowerShell treats as one
Bug: gemini_command wrapped the script path in PowerShell `& '...'` and doubled only the ASCII
apostrophe. PowerShell also ends a single-quoted string at U+2018, U+2019, U+201A and U+201B, so a
home folder holding a curly quote (O’Brien) broke every Gemini CLI hook; on macOS/Linux the
PowerShell form was emitted too.
Fix (src-tauri/src/agent_hooks/vendors.rs gemini_command): on Windows every one of the five quote
characters is doubled; elsewhere the path is POSIX single-quoted with '\''.
