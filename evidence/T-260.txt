What is built
- src-tauri/src/activity.rs: each pane keeps its state changes (Mark {at, state}) in memory, a
  repeat of the current state adds nothing, changes older than 26 hours go except the last one
  before the reach, at most 500 per pane; end() records when the pane closed and a pane closed
  before the reach leaves the Floor. New command activity_timeline returns one Track per pane with
  its terminal (status::terminal_of) and live (the terminal is still open).
- src/floor/timeline.ts: rangeStart (15 minutes, 60 minutes, today = local midnight), kindOf
  (working; permission, waiting, blocked = needs you; anything else idle), segments (clamped to the
  range, nothing after the pane closed, idle reads unverifiable when the terminal is gone), ticks
  (six, both ends included), lanes (pane order, empty lanes left off).
- src/floor/FloorView.tsx: the Floor page with the three range buttons, a legend, one lane per
  pane and six HH:MM ticks; it polls activity_timeline every 5 seconds.
- src-tauri/src/notifications.rs: welcome_step (not a Mac = unsupported and never probed; a Mac
  that answered = never asked again; otherwise ask) and first_run_welcome, which on a Mac shows one
  welcome notification and records the answer only if the system shows it within 30 seconds.
