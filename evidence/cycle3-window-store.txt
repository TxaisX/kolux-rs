2. THE SOURCE-TEST FILE LIST

Which test: src/plainWords.test.ts (ONB-036). It enumerates source files in its own SOURCES list and
asserted a hardcoded size:
  before: `expect(SCREENS).toHaveLength(38); // a renamed file must not drop out of the scan silently`
Its list had grown to 38 entries (18 newcomer screens + the 20 files of the cycle-2 App.tsx split). Adding
a module and not adding it to the list left the count at 38, so the test kept passing and the module was
silently outside the scan.

The list's helper, src/shell/windowSource.ts, had the same weakness: a hand-written 21-path
import.meta.glob list. A module moved out of WindowView.tsx into a new file was outside every source test
that reads windowSource (paneStatus, paneMark, commands, savedLaunch, noticeMount, explorerBar,
main.slowStart) until someone remembered to add it.

What changed:
- src/shell/windowSource.ts: the drawing is now a folder, src/shell/window, and the list globs it whole
  (`./window/*.{ts,tsx}`, tests and __cards__ excluded) instead of naming files. A new surface module is
  in the text by existing. It also exports `windowFiles` (path -> text); the window's 21 files outside the
  folder stay one named list.
- src/plainWords.test.ts: merges `windowFiles` with an 18-entry base-screen glob. Every window file is
  scanned for its toasts/notices only, as App.tsx and the cycle-2 split files were. The hardcoded 38 is
  replaced by a named guard: the 18 base screens are asserted, and every windowFiles entry must be in
  SOURCES. A new module needs no edit; the plain-word scan cannot lose it.
- src/shell/windowSource.test.ts (new, 3 tests): (a) every file in src/shell/window is in windowFiles and
  in the joined windowSource text; (b) the 21 files outside the folder are present (a rename fails the
  count); (c) every local module WindowView.tsx imports resolves to a key in windowFiles.
- Nothing was deleted or weakened: all existing tests remain; the count guard moved from 38 hand-listed
  files to 18 hand-listed screens plus a whole-folder glob, and the new test covers what the old count did.
