lane/setup from 0819c57 · 2026-10-13 · all in src-tauri/src/setup.rs

Rules and where they are built:
- Local settings win by default even when kolux.yaml has a command; the older shared-first policy uses kolux.yaml only:
  pick_setup(local, shared, policy); workspace_setup(path, local?, policy?) takes the repository's own Kolux setting and the policy
  ("shared" / "shared-first"); existing callers pass only path and keep kolux.yaml's script.
- Setup steps are read from the kolux.yaml inside the worktree being created: workspace_setup reads <path>/kolux.yaml (unchanged).
- Archive script: run_archive / workspace_archive read scripts.archive from the removed worktree's kolux.yaml (OD-14: no per-repository
  archive setting), run it inside that worktree with no window, KOLUX_ROOT_PATH (main folder from the worktree's .git file),
  KOLUX_WORKTREE_PATH and KOLUX_WORKSPACE_NAME set, and stop it after 120 s.
- The Setup terminal now gets the same three variables: with_env puts `export NAME='value'` lines (POSIX) or `set NAME=value&&` (cmd,
  a value cmd would misread is left out) ahead of the script; the script text itself (kept for the trust fingerprint) is unchanged.
- Windows batch scripts run under the classic command prompt even when the user's shell is Git Bash: setup_line sends a script whose
  first word ends in .bat or .cmd to cmd.exe /d /s /c (cmd's refusals still apply).
- A partly activated conda environment is not used: conda_partial (CONDA_PREFIX set but its folder not on PATH) clears CONDA_PREFIX,
  CONDA_DEFAULT_ENV, CONDA_SHLVL and CONDA_PROMPT_MODIFIER for the archive run and for the Setup terminal line.
- Not here: COMPAT 5.5's two root-path aliases (their names are not written down) moved to T-110-b's line; the trust prompt before a
  shared kolux.yaml script runs is T-156 (SAFE-025).
