T-125-b (bell part) · lane/fix-term, 2026-10-25
Finding: the xterm bell already reached the window (TerminalPane term.onBell -> onBell -> App noticed(p, "rang the bell")), but
noticed() was called with no switch, so the bell raised a FINISH note: kind "finish", tray_ping("finished"), gated by the
"agent finishes" switch, and the "A terminal rings its bell" switch (notifyBell, default off) was never consulted.
Fix: src/terminal/bellNote.ts BELL_NOTE = { what: "rang the bell", gate: "notifyBell" }; App passes it, so noticed() derives
kind "bell" -> raiseNotification (notify_event kind "bell") + tray_ping("bell") and honours the bell switch. TerminalPane now
lets one bell through per 2 s per pane (bellGate), so a program ringing in a loop raises one note.
Patch (App.tsx is shared): evidence/fix-term-fix-125-b-App.tsx.patch (git apply --check passes; also with fix-term-fix-T-066-d-App.tsx.patch).
Tests (fail without the module): src/terminal/bellNote.test.ts 3/3; vitest src/terminal 495/495; tsc 0.
Rest of T-125-b, not mine: the OS toast click (notification_clicked exists; the plugin drops the click handle, so no activation
reaches the app) and the hook sequence number as event id (fix-ui, useAgentStatus.ts).

view: one note "<tab> rang the bell" and the tray dot lights; a second bell within 2 s adds nothing.
