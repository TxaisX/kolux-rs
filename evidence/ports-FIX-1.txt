WHAT CHANGED (what the user gets)
- Stop can end only the program the row showed: the port's holders are re-read at the click and must
  be exactly the shown process number, and that process's start time is re-read right before the kill,
  so a reused process number is never stopped.
- Stop is licensed only by a workspace the project store knows (saved projects + their git worktrees),
  that is deep enough (never a drive root or a top-level folder), not the home folder or anything above
  it, and that is a real git folder. Kolux itself, Kolux helpers no pane started (WebView2) and system
  process numbers (0-4) are never stopped; system listeners show as external.
- The status bar lists other workspaces' ports as external instead of dropping them, and only the
  active workspace's rows get a Stop (App.tsx hunk: evidence/ports-FIX-1-App.patch).
- Reading another program's working folder trusts its string length only when even, non-empty and at
  most 32 KiB; the SAFETY comment says what is relied on; a 32-bit Windows build is refused at compile time.
- A printed address is tied to the terminal that printed it and to the program first seen on its port;
  each terminal has its own streaming text decoder, so a non-ASCII address split across chunks survives.
- The real-server test fails (not passes) when node is missing.
