T-140-b · AUTO-014 the agent's transcript is preferred over the screen text · lane/automations from a3375e77 · 2026-10-19 · Claude Sonnet 5.5

What the user can now see: a finished automation run's saved output is what the agent itself said
(its assistant messages, in order, no tool calls, thinking or side chains), taken from the agent's
transcript, instead of the terminal's raw screen. The note under the output says "What the agent
said during the run, from its transcript." (or "The most recent of what the agent said; older text
was left out." past the 16,000 character limit). When no transcript can be found or read, the run
keeps the pane's text exactly as before.

Second half of the card (a run whose pane closed first keeps the pane's last text): already on main.
terminal.rs reads the pane's log into the exit closure before dropping it and hands that text to
automations::keep_output (pane_ended + keep_output through automations::follow). No terminal.rs
hunk is needed, so the PLAN note about one was stale. No patch for this task.
