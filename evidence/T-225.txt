What the user gets
- Source Control lists Changes, then Staged, then Untracked by default (conflicts stay pinned on
  top); the group-order setting offers Changes first, Staged first and Untracked first.
- In tree view a chain of folders that each hold only one folder shows as one row (a/b/c); a
  folder with more than one child keeps its own row. Closing the folded row closes it as one.
- A section with a very large change set lists its first 500 rows and then says, in one line,
  how many more there are and how to reach them ("1,234 more files are not listed here, so the
  panel stays quick. Type part of a path in the filter, or open All Changes, to see them."). The
  section's count and its Stage all / Discard all buttons still cover every file.
