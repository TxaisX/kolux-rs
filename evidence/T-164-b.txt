# T-164-b evidence: Reopen Closed Tab brings back terminal tabs (lane/chrome 2026-10-20, Routing v3)

No app launch (builder rule). Card: TERM-047 (Mod+Shift+T brings the last closed terminal tab back in its previous folder;
ten remembered, newest first; a folder whose path form is gone is remapped).

## What was built
- src/chrome/reopenTab.ts (lane-owned): closedRecord (what a closed tab needs to run again: folder, branch, agent mark,
  agent id, program, args, env, title, word; no session, typed line or ask), createClosedPanes() / closedPanes (remember
  in close order, take the newest), paneFor, placement. It uses src/terminal/closedTabs.ts (remember, pathForms, reopen)
  unchanged. Browser pages keep their own ring (src/browser/pages.ts); this file keeps a close-order list so one
  Mod+Shift+T undoes whichever kind closed last.
- "Does this folder exist" is answered by the existing path_kind command (kind "dir" counts); the forms tried are
  pathForms(cwd); none found = the shown workspace (activeDir), none shown = no workspace. A pane that had no workspace
  comes back without one.
- Placement: the focused cell when the focused pane is in the same folder, else a cell of its own, or the first cell
  when the workspace already shows MAX_PANES (12).

## Patch for the merge resolver
evidence/chrome-T-164-b-App.tsx.patch (git apply --check passes on this tree): the import, dropPanes calls
closedPanes.remember(panes, keys, rememberClosed) in place of the bare rememberClosed loop, and tab.reopenClosed takes the
newest close (terminal -> add the pane, show its workspace, focus it; browser -> the existing takeClosed/openInBrowser).
tsc --noEmit with the patch applied: exit 0 (log G:/Temp/chrome-v3-logs/tsc-patched164.log); vitest src/chrome +
src/terminal/closedTabs + src/browser/pages with it applied: 10 files, 61 tests pass. Patch reverted afterwards.
Without the patch nothing changes in the app (the new module is unused).

## Unit tests (src/chrome/reopenTab.test.ts, 10 tests)
- closing three tabs and reopening three times brings all three back in reverse order, a fourth finds none;
- after 11 closes only the 10 newest come back (t11 .. t2);
- a gone folder comes back in a spelling that exists, else in the home folder; with no home, without a workspace;
- a pane that had no workspace stays without one; a failing path check counts as missing;
- browser pages and terminal tabs undo in close order; browser/editor/launch-sheet panes are not remembered as terminals;
- a reopened tab keeps program/args/env/title but not session, typed line or ask;
- placement: same-folder focus, other folder, and a workspace at 12 cells.

## LIVE PROOF PENDING (batched), after the patch is applied
1. Open two terminal tabs in one workspace, close both (Mod+W), press Mod+Shift+T twice: both come back, newest first,
   in the same folder, running the same program.
2. Close a terminal tab, close a browser tab, press Mod+Shift+T twice: the browser page returns first, then the terminal.
3. Close a tab of a workspace, switch to another workspace, press Mod+Shift+T: the old workspace shows with the tab.
4. Close 11 tabs; 10 reopen, the 11th press does nothing.
5. Delete the tab's worktree folder, close its tab beforehand, reopen: the tab opens in the workspace on screen.
