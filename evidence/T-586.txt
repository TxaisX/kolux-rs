T-586 (status-hooks lane, 2026-10-30): terminal link click areas count screen cells, not string positions
=========================================================================================================
Audit L3-terminal-editor-js.2 (src/terminal/links.ts:137) and ponytail note src/terminal/tabs.ts:51. Cards TERM-092
(web links, "A URL wrapped over two lines opens as one complete address"), TERM-093 (file paths), TERM-096 (term-N).

THE PROBLEM
The link providers read each row with translateToString, which gives a wide character (CJK, U+2705 and the other
emoji Kolux's Unicode 16 table makes two cells wide) one string index but two cells, and an emoji built of surrogate
pairs or a ZWJ sequence several indices but its two cells. spanOf padded wrapped rows to `cols` string characters and
rangeOf turned a string index straight into a column, and the term-N provider did the same. So link underlines and
Ctrl+click areas slid left after wide characters (right after surrogate pairs), and a link wrapped after wide
characters was cut in two by the padding, so a Ctrl+click opened a cut-off address.

WHAT CHANGED
- src/terminal/links.ts:8 imports find.ts's linesOf (which the find bar already uses to put string indices on cells).
- src/terminal/links.ts:107-149 Row is find.ts's BufRow (a row's cells, or a string standing for one cell per
  character); spanOf joins the logical line through linesOf and returns, with the text, the cell each index starts in
  and the cell after it (Span); rangeOf places a [start, end) span through those cells.
- src/terminal/links.ts:151-193 Buf/BufLine (xterm's IBuffer/IBufferLine as far as needed), rowOf (a full ASCII row
  as its string, any other row cell by cell with getChars/getWidth), linksIn (web and file links of the logical line
  holding a row) and handlesOn (the term-N handles, now placed the same way, wrapped lines included).
- src/terminal/TerminalPane.tsx:499-508 and :551-558: both link providers call handlesOn / linksIn; :1297-1306 the find
  bar's own copy of the cell reader is replaced by rowOf (same rule, one place).
- src/terminal/tabs.ts:50-51 the ponytail note ("string offsets, so a line with wide characters before a handle puts
  the link a little off") is deleted: fixed.
- src/terminal/links.test.ts: the older span tests use the BufRow shape (cells, wrapped) and the new rangeOf
  arguments; every assertion they made is kept.
