DECISIONS (coordinator default; Txais may overrule; rows in state/kolux-rs-after.md)
- "Settled" = the trust question answered and the Setup terminal opened (or a visible reason it did not run); the
  agent waits for the script's end only when the repository's wait-for-setup is on (new-tab mode, PROJ-033).
- A setup that cannot start does not stop the launch; it is said in the notice bar and the agent starts.
- "Bulk launch" = a Start from the session chooser / New session page that makes new workspaces; seats in an
  existing workspace are not refused.
- The mode lives per repository next to its policy and wait choice (setupModes); no global setting.
