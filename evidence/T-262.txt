T-262 · ORCH-060 Session tab inventory the command line and agents can read
Date: 2026-10-13 · lane/orchestration from 07c5d80

What was built
- The runtime publishes one session tab inventory: the Tauri command `session_tabs`
  (src-tauri/src/inventory.rs, mounted from agents.rs as agents::inventory). Each row:
  handle (term-<n>), agent (the agent Kolux started in the tab, null for a shell), program,
  cwd, title, placement { pane, tab, shown } (null until the window has placed the tab).
- The list is the live session set joined with the window's latest placement report: a stale
  window row for a closed session adds nothing; a session not yet placed is listed unplaced.
- agents::inventory::tabs(&Terminals) is the single function behind it; the command line's lists
  (cli.rs, cli lane) switch onto it with the hunk in the lane handoff (T-262 section).
