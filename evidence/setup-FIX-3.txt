What changed
- Item 2 (FIX-SOON 1): words_before cuts folders at / and at \ (it split words on \ before) and returns Word{name, raw,
  folder}; folder is true for a word that had a folder part and is no .exe path. runs() is true when the command word is
  the program, or after a launcher any word, or when ANY other word that is not a folder path is the program. So
  C:\xampp\mysql\bin\mysql.exe -u root -p, .\7z.exe a -p, & "C:\Program Files\7-Zip\7z.exe" a -p,
  C:\Windows\System32\curl.exe -u, sudo -n/-i/-s/-S mysql -p, env -i mysql -p, if x; then mysql -p; fi, winpty mysql -p
  and echo "mysql -pS3cret" >> ~/.bashrc are hidden again; find /var/lib/mysql -perm 644, cat .../my.ini -pfoo and
  dir C:\tools\curl -u a:b stay as typed. Wrapper options are per wrapper and case sensitive (takes_value): sudo -n/-i/-s/-S
  and env -i take no value, sudo -u/-g/-C/... and env -u/-C do. then, do, else, !, {, if, elif, while, until and winpty
  pass through. Decision: when the command word is a pure search tool (grep, egrep, fgrep, rg, ag, ack, man, which,
  where, whereis, type) the program word after it is only a pattern, so grep curl -u admin:hunter2 notes.txt stays as
  typed (it stayed in FIX-2's list and the review did not ask to remove it); echo curl -u admin:hunter2 is now masked and
  is removed from the stays-as-typed list as asked.
- Item 3 (FIX-SOON 2): in segment_start a ' inside an open " is literal unless a matching ' comes before the next
  unescaped " (apostrophe_closes). mysql -u root -e "select 1; -- don't" -pS3cret and curl "https://x/?q=it's&a=1" -u
  admin:hunter2 are masked.
- Item 4 (AFTER 1): per-assertion red probe, below.
