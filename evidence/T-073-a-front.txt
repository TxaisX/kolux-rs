Shape built against (for files.rs):
- file_write(path, text, loaded_hash: Option<String>): the JS side sends { path, text, loadedHash }
  (Tauri maps loadedHash to loaded_hash). loaded_hash is the lowercase hex SHA-256 of the file's
  bytes as file_read returned them (read_text is lossless UTF-8, so text bytes = file bytes).
  Absent (Keep mine) = write without a check.
- refusal: error kind "stale", either an object { kind: "stale", ... } or a string starting
  "stale" (Err(String) as today). Any other error stays a toast, as before.
