   the exact argv. Windows (taskkill) is unchanged.
2. src-tauri/src/git.rs command(): on Unix git leads its own process group (process_group(0)), so
   the group kill a stalled short read gets (git.rs stopped -> procs::kill_tree) also ends the

   the Rust unit tests compile off Windows (audit X-proc.8).

   selector start at the line start, so the test reads the CSS the same on CRLF and LF checkouts
   (audit X-proc.3).
5. scripts/test-env.ps1 (new) and scripts/test-env.sh (new): make the scratch homes the integration
   tests require (marker .kolux-rs-scratch with home, claude-config, codex and tmp folders), point
   USERPROFILE, HOME, CLAUDE_CONFIG_DIR, CODEX_HOME and TEMP/TMP/TMPDIR at them, keep the real
   CARGO_HOME and RUSTUP_HOME. .github/workflows/ci.yml: the Rust tests step dot-sources
   test-env.ps1 (audit X-proc.4, X-test.2). CI layout otherwise unchanged.
6. src-tauri/src/scm.rs:1317: the raw NUL byte in t.split('<NUL>') is written as '\0', so grep and
   ripgrep read the whole file (the audit's first pass missed nine ponytail notes because of it).
