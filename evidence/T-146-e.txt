WHAT WAS BUILT (new shell-owned src/space/**)
- src/space/SpaceView.tsx: the Space page. Saved sizes show at once (space_saved), then a scan (space_scan) refreshes them;
  Rescan button. A fixed 320 px square treemap from treemap() (biggest 24 blocks + one "N more" block, title = label and
  size). Table: branch, folder, size, file count, age, state (Main / In use / Deletable / Kept); sort select (biggest,
  most files, oldest, by branch), search box, "Deletable only" filter, a checkbox per row, "Delete selected (n)".
  Delete: selectedForDelete drops main and in-use rows, then every remaining row gets the same safety check as a single
  delete (workspace_remove_check); rows with uncommitted changes, a lock or a nested worktree are skipped with the reason.
  The question lists what comes back and every skipped row; confirm runs workspace_remove_many with force false and the
  checks' stamps (PROJ-083: the safety-checked confirmation, never force). Removed rows leave the table; the batch summary
  and any per-row problem show as a note.
- src/space/view.ts (pure; 5 vitest in view.test.ts): labelOf, activeOf (a pane open in the worktree = in use, slash and
  case blind through sameDir), stateOf, treemapItems, plan (checks -> picks + skipped), question (wording, null when
  nothing goes), afterBatch.
- "In use" = any pane whose cwd is in that worktree (App.tsx's openDirs: browsers, agents and shells alike), a stricter
  reading of VIEW-014's "open browsers or running agents" (coordinator default; on kolux-rs-after.md).
