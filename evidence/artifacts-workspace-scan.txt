Artifacts: import a workspace's artifacts folder automatically, and play media in the tab
Date: 2026-10-31
Lane: lane/artifacts-auto
Base: 282ae0be (origin/main)

Why
The library only knew pages added by hand and files Claude Code's Write tool made (DT-C58).
A file written by another agent, such as the design artifact in this workspace's artifacts/
folder, stayed invisible until Add artifact and a trip through the file picker. The user asked
for it to land in the tab automatically, and for video, audio and other files to work there.

What changed
- src-tauri/src/artifacts.rs: artifacts_scan(path, project) and workspace_files(). The scan reads
  the top-level files in <workspace>/artifacts, imports each once, refreshes a changed file by its
  origin instead of adding a second entry, skips entries the library already holds, emits
  artifacts-changed, and leaves relative paths and network shares alone. Top-level only, so a test
  run's shots/ folder is not imported; a page's own relative assets are still copied with it.
  JSON and log data count in the explicit artifacts folder but not in the global Claude Write list.
- Media: mp4, webm, mov, m4v, ogv, mkv, avi, mp3, wav, m4a, ogg, oga, flac, aac and opus are kept
  and typed as video or audio. The single-file cap rises from 25 MB to 100 MB. The artifact scheme
  now answers byte ranges (206 with Content-Range and Accept-Ranges) so a video or audio track can
  seek without loading the whole file.
- src-tauri/src/lib.rs: registers artifacts_scan.
- src/artifacts/ArtifactsPage.tsx: scans when the page opens and every 3 s while it is up, and
  refreshes the list when the scan imported something. Video plays in a native player, audio gets a
  player panel, PDF is shown in the frame with an Open PDF fallback, and the Add dialog has a Video
  and audio filter.
- src/shell/window/Content.tsx: passes the active workspace and its project name.
- src/styles.css: the media, audio and PDF viewer surfaces.

Proof
- cargo test --lib artifacts::tests: 10 passed, 0 failed. The tests cover workspace selection and
  exclusions, first import, unchanged second scan, refresh of a changed file, a fresh app run not
  re-adding entries, media kinds and MIME types, range parsing and clamping, and a real media file
  served through the scheme as a 206 with the requested bytes.
- pnpm exec tsc --noEmit: pass.
- pnpm exec vitest run src/artifacts/ArtifactsPage.test.ts: 5 passed, including video, audio and PDF
  view modes.
- pnpm check: pass. invoke-contract: 705 invoke calls by name against 445 registered commands.
- pnpm build: pass.
- cargo clippy --lib -- -D warnings: clean.

Live proof pending
This lane has not been launched as a GUI in this pass, so the command has not been exercised through
the running app. On the first Artifacts open with a workspace that has a top-level artifacts/ file,
the file is imported automatically. A video or audio entry plays in the tab; a PDF shows in the
frame; other documents offer Open. The 30 second Kolux ad MP4 in the vault is 7.7 MB, well under the
100 MB cap, and its range requests are covered by the scheme test.
