T-043-c (ACCT-007 Codex connects with a ChatGPT sign-in or a device code)

No real sign-in was used. Every screenshot was taken with a stand-in program named codex.exe,
compiled for this check and put first on the dev app's PATH. For `login` it prints a made-up
sign-in link (auth.example.invalid) and, with --device-auth, a made-up code (FAKE-12345), waits a
set number of seconds, then writes a fake auth.json into CODEX_HOME (fake tokens, made-up emails
kim@example.com and lee@example.com). It opened no browser and contacted no one. The stand-in,
its throwaway repo and the test accounts were deleted after the check.

The user's usual Codex folder (%USERPROFILE%\.codex, 11,903 files) was fingerprinted with SHA-256
before the app started and again after it closed: every file was byte-for-byte unchanged (one file
held open by another program could not be read either time). The sealed vault copies of the two
test sign-ins started with "kolux-sealed:v1:".

Found live and fixed: the hidden console places lines by moving the cursor, so two screen lines ran
together and the link read ".../device2"; strip_ansi now turns a cursor jump into a line break and
a cursor-forward move into a space (unit test added).
