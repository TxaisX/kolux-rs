WHAT CHANGED (src-tauri/src/orchestration.rs)
B1  A failed worker start's way out now runs, in order. A worker that did not answer is
    stopped first (worker-stop --dispatch, which frees the task) whether or not a terminal was
    seen; a failed setup's leftover terminal is released; the retry is a plain
    `worker-start --task <task>` (the old `--retry-of` form was refused because the task was
    still dispatched). New start_check(tasks,id,run) is the one check worker-start uses, so the
    test runs the way out against the real refusal.
A2  The worktree-remove command quotes the path ("path:<p>"), so a folder with a space pastes
    as one word.
A3  keep_open's dead `launch == "reused_terminal"` branch removed; a non-null mode is the
    "handed already open" record.
S1  keep_open also asks what the terminal runs now (agent_of): another agent than the worker's,
    or a shell / non-agent program, stays open with the reason. New worker_terminal(fresh,
    agent) picks a session only when exactly one terminal that appeared during the start sits
    in the worktree and runs the agent (wired by the cli hunk's wait_ready).
S2  stop_with applies keep_open: a terminal left open is not killed, the process reads
    "unverifiable", the dispatch and receipt carry terminalLeftOpen, and stop_warning says
    "the worker's process was left running: <why>". stop() and release() are kept as wrappers
    (passing "cannot tell") so the in-flight T-089-c cli patch still compiles; release_with is
    the real release, called once the cli lane wires it (#[allow(dead_code)] until then).
S4  worker_label goes through one_line: ANSI/cursor codes stripped (terminal::strip_ansi),
    every other control char and invisible direction/width mark (U+200B-200F, 202A-202E,
    2066-2069, FEFF) turned to a space first, whitespace folded, cut to 60.
S3  fixed on the cli side (created = now_ms()); attention's made-at < 1e12 guard is unchanged.
