LIVE PROOF PENDING (after-list row 392, CHAT-008: older chat pages come from the backend on demand)

Needs a running app and a real long transcript, so a builder did not run it. The resolver runs it on main.

Steps (scratch HOME and profile per the SAFETY rule; a throwaway project with a Claude-format transcript of a few thousand lines):
1. Open the pane in chat view. The chat opens quickly on the newest 1500 transcript lines; the newest 300 rows show.
2. Press "Load earlier messages (200 more)" repeatedly. Rows already read show first (200 a press).
3. Once every row read is shown, the control reads "Load earlier messages" (no count). Press it: the next 800 older lines
   are fetched (chat_read with cursor + limit), appear above, and the message that was at the top of the view stays where it was.
4. Keep pressing until the beginning: the control disappears.
5. While a page is loading, leave the chat (hide) and return: the late page is dropped, no duplicated rows.
6. Append to the transcript while older pages are shown: new messages still arrive at the bottom.

Unit proof now: cargo test chat:: (row392_* seven tests), vitest src/chat/earlier.test.ts and page.test.ts.
