T-140 · AUTO-014 Saved run output with token and cost figures (lane/automations from 0819c57, 2026-10-13)

What the user gets
- A finished agent run keeps the most recent text its terminal showed (escape codes stripped,
  progress-bar redraws down to their last frame, blank stretches squeezed, past 16,000 characters
  only the latest text from a whole line, marked "older lines were left out").
- Opening the run (Runs > a run) shows "Saved output" and a "Tokens and cost" line: tokens and
  dollars matched from the agent's own local usage log (Claude, Codex) in the run's worktree
  between its start and one minute after its end. A model without a known price reads
  "cost unavailable", an unmatched run or tracking off reads "Unavailable: ...", never 0, and an
  agent with no local usage record reads "Not supported: <agent> keeps no local usage record".
- The automation's Overview "Usage" row adds the matched runs up ("N tokens over K runs · $x").

src/automations/usage.ts (runUsage, usageWord, totalUsage), RunsDashboard.tsx (RunPage),
AutomationsPage.tsx (reads token_usage, scans tracked agents once on open), model.ts (Run fields).
