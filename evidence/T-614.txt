WHAT CHANGED
- src/projects/useWorkspaces.ts:49-52  a ref holds the panes as last drawn (panesNow), so a removal that finishes after
  long awaits reads the tabs as they are then, not the copy from the render in which the delete was clicked.
- src/projects/useWorkspaces.ts:99-112  removedAll(): setPanes(without) is a functional update built on the newest list
  (a tab opened meanwhile stays and its process lives; a tab removed earlier never comes back); siblings, the next
  active workspace and the focus are computed from the fresh list.
- src/projects/ProjectsPanel.tsx:120-122, 206  new optional prop onRemovedAll(paths) (default: onRemoved per path, so
  the panel still works where nothing passes it).
- src/projects/ProjectsPanel.tsx:1179-1198  removeBatch (Delete all on a parent) collects the removed paths and calls
  onRemovedAll once, in finally, so a batch that stops part way still closes the tabs of the ones that went.
- src/projects/ProjectsPanel.tsx:2064  the cleanup dialog's removal calls onRemovedAll(paths) once (was paths.forEach).
- src/projects/ProjectsPanel.tsx:2244 and src/shell/ProjectsExtras.tsx:88-89, 120-138  the multi-select bar's
  onRemoved takes every path in one call, at the end (finally).
