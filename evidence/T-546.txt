T-546 · OD-09 control tower · lane/look · 2026-10-13

What was built
- src/tower/tower.ts: the pure model. towerRows(seats) orders every agent pane needs-you first,
  then working, done, stopped, idle; newest change first inside a lane, pane key as the tie-break;
  a pane with no signal yet reads as idle; each row carries the pane's own key as the jump target.
  laneCounts(rows) feeds the summary card. usageByAccount(seats, plan) gives one usage card per
  (program, account) pair with the provider's 5-hour / weekly figures from src/usage and the
  number of panes under it (Claude and Codex only; shells are not agents).
- src/tower/TowerView.tsx + tower.css: the screen. Summary card (count + per-lane counts, or
  "Nothing is running. Start an agent and it shows up here."), one usage card per account, then
  the rows grouped under Needs you / Working / Done / Stopped / Idle headings. Each row: status
  glyph, pane name, program + account, branch · folder, what it is doing (word, line, file),
  context ring and plan figures when known, time since the last change. Click or Enter opens the
  pane (onOpen = App.openPane); Up/Down move the selection. Same tokens and 30 px row density as
  the Board and Inbox.
- Wiring (App.tsx, chrome/TopBar.tsx, keys/actions.ts, keys/keymap.test.ts) is NOT in this commit:
  those files belong to other lanes. The hunks are applied locally for the proof and the smoke and
  live verbatim in the lane handoff (RE-APPLY ON MERGE) and the batch report.
