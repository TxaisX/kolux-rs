WHAT THE USER CAN NOW DO
- (3) A skill delete whose hidden set-aside copy cannot be removed yet (another program holds a file in
  it) no longer makes every later delete fail with "an earlier delete is still being cleared up; restart
  Kolux". The leftover is carried into the next delete's record, those deletes go through, and the
  leftover is removed at the next start (or the next delete) once it is free. A not-done record that
  could not be put back is still never written over.

  two-writers race the review named). evidence/T-180.txt line 14 is corrected to say this.
