T-180 · SKILL-022 Delete skills safely from the Skills page (+ the SKILL-017 menu rule)
Lane: skills · branch lane/skills · base 950ba36 (fast-forwarded from d1de182 in STEP 0) · 2026-10-14

WHAT THE USER CAN NOW DO
The Skills page's more-actions menu item "Delete skills" is live: it opens a selection mode with
"N selected", Select all eligible, Clear, Delete... and Exit selection. Bundled and plugin rows show a
disabled checkbox with the reason. Delete... asks first: the confirmation counts the folders and links
across all roots, names where the content stays when only a link goes, lists blocked skills with their
reasons, says "This cannot be undone." and has a destructive confirm button. After confirming, each skill
gets its own outcome (deleted / skipped / busy / partly removed / failed with nothing changed).

CODE
- src-tauri/src/skill_delete.rs: one lock shared by skill delete, install and update (skill-op.lock in the
  app folder; a lock left behind past 15 minutes or by a dead holder is taken back; a live one gives "busy");
  plan() (the confirmation's facts, changes nothing) and run() (re-checks every pick, sets each folder or
  link aside, then removes it; an unfinished delete is recovered from its journal first). Blocked reasons:
  bundled, plugin, outside Kolux's skill folders, no longer on disk, changed since the list loaded.
  A request holds 1..=512 picks. Tauri commands skills_delete_plan, skills_delete.
- src-tauri/src/skills.rs: walk skips set-aside items; places() (home + workspace skills folders that may be
  deleted from, plugin folders that never are); occurrences() (every skill folder AND every link to it
  under a root, so a skill and its link in another root go together); forget_scans() (next list is fresh).
  occurrences() never opens a share: share roots, links to shares and SKILL.md links to shares are skipped
  (the same rule main's c611b8a gave the scan).
- src/skills/skills.ts: MAX_DELETE, canDelete, pickOf, whyNot, eligible, keepChosen, sumUp, BLOCKED,
  OUTCOME, outcomeText. src/skills/SkillsPage.tsx: the selection mode, confirmation and outcome list.
- Receipt convention chosen (decision for Txais): "<folder>.receipt.json" next to a skill folder is removed
  with it.
