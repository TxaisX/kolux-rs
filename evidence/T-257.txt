- src/status/credit.ts (new, 4 tests in src/status/credit.test.ts):
  · launchedAgent(pane): the launch record names the agent: the pane's catalogue id (agentId), else its own
    agent (claude / codex), else the agent its program runs (launch/paneMark creditedAgent, the rule Rust shares).
    A browser or other non-terminal tab and a kit's multi-seat tab have none. launchedName gives the catalogue
    name (keys/actions agents: "MiMo Code", "Cursor", "Pi").
  · titleNames(title): the title patterns, tried in order with each match cut out before the next: oh-my-pi / omp,
    cursor / cursor-agent / Cursor Agent, mimo / MiMo Code, claude, codex, then the Pi-style title (the word pi or
    the pi sign), which Pi and OMP share. A name inside a longer word ("pipeline", "recursor") and a bare path
    never count.
  · titleCredit(launched, title): the launched agent plus STAT-033's titleState of the title, and whether the
    title named it (dot and row agree). Null with no launch record, and null when the title names only some
    OTHER agent (Cursor running a Claude model and printing "Claude ... spinner" claims nothing for anybody).
  · titleGuess(launched, title): the state a pane takes from a new title; a plain shell (no launch record)
    keeps STAT-033's reading unchanged. creditedLive(launched, live): TERM-058's live identity with any agent the
    title names that is not the launched one dropped, so the icon stays the launched agent's.
- src/status/working.ts (T-259 / STAT-036, 2 new tests in working.test.ts): countsAsAgent counts a pane by its
  launch record (so Cursor, MiMo and Pi count, not only Claude and Codex); workingByDir takes the panes' live
  titles: hook state first, then the launched agent's own title state (only while its program has not ended and
  only when the title names no other agent), then the program-up guess.
