  off) turns it on and off live for every open editor tab.

T-316-b piece 2 (2026-10-20, lane/editor): Jupyter notebooks (EDIT-024), without the Python run.

BUILT
- src/editor/notebook.ts (pure model): parseNotebook (says why for an empty, non-JSON, cell-less or damaged file),
  serialize (Jupyter layout: one-space indent, final newline), sourceOf/withSource (a cell stored as lines stays lines,
  as one string stays one string), insertCell/removeCell/moveCell, setKind (code, markdown, raw: leaving code drops outputs
  and run count, arriving gives empty ones; text, id, metadata stay), limited (a long cell shows its first 200 lines or
  20000 characters), outputText (streams, text results, errors as plain text, pictures as a note; never HTML). Every
  field the view does not show (metadata, kernel, ids, outputs, unknown fields) stays in the object, so an untouched
  notebook serialises byte for byte and an edited one keeps all else.
- src/editor/NotebookView.tsx: the cells view. A .ipynb tab opens in Cells with Source beside it (viewSwitch already
  offered that pair); each cell is a text box with a type menu and Up, Down, Remove; "+ Code / + Markdown / + Raw" between
  cells; saved outputs under code cells as text; a long cell shows its start and "Show all N lines". Typing is sent back
  300 ms after the last key or on leaving the box; every change goes into the tab's own text, so Save, undo, the source
  view and the dirty mark all work. Read-only tabs show no controls.
- EditorPane.tsx: grid covers notebooks; the switch button reads Cells for a notebook.
- Trust: there is no run button, so a notebook cannot run by being opened or edited; the trust prompt and run ride on the
  Python launch and stay with the interpreter work (skipped by the brief).
TESTS: src/editor/notebook.test.ts 13 tests (read errors, exact multi-line source, byte-for-byte round trip, unknown
  fields kept, string vs line source, ids for 4.5 only, clamped insert, move/remove, kind switch, preview limits, output text).
READINGS: vitest run src/editor: 63 files, 418 tests passed (g3-vit.log); tsc --noEmit exit 0 (g3-tsc.log);
  vite build exit 0 (g3-build.log). No Rust, no shared file, no patch.
