Lane editor, from ab6c9df2 (main d823b3f8 merged in first). No app launch (batched live proof below).

What changed
- EDIT-006 word wrap (src/editor/EditorPane.tsx): editor tabs now wrap long lines by default; the saved
  "editor word wrap" setting (Settings > General, already stored by T-323) decides once it loads; Alt+Z
  (the existing editor.toggleWordWrap chord, so a rebinding keeps working) flips it for the tab and saves the
  setting. The editor font already follows the terminal font and then a monospace fallback (theme.ts
  --editor-font), and text size follows the app zoom (settings/zoom.ts), so those parts needed no change.
  NOT built: the minimap (see T-316-b).
- EDIT-010 colouring (src/editor/languages.ts): Vue was already in the built-in set; Astro and Svelte now use the
  HTML language (script and style sections coloured in their own languages), Nim has its own tokenizer
  (keywords, types, strings, numbers, # comments), JSON Lines is read one JSON value per line (keys, strings,
  numbers, true/false/null, brackets). The edit tab, the diff tab and the combined diff all use languageFor, which
  also matches upper-case extensions. Ceilings: Astro front matter and Svelte {#if} blocks are coloured as plain
  HTML text; Nim #[ block comments ]# and triple-quoted strings are plain text.
- EDIT-011 icons and order (src-tauri/src/files.rs list_dir; src/editor/fileIcons.ts, FileIcon.tsx): the explorer
  lists folders first, then names in natural order (file1, file2, file10) with ties settled by the exact name,
  never disk order. Each file gets a small icon by kind: a whole name (lock files, package.json, Dockerfile,
  .gitignore, tsconfig*.json, README, LICENSE, .env*) wins over the extension, multi-part endings are read
  (.test.ts and .spec.ts are test files, .config.ts is config, .tar.gz is an archive). The icon shows in the
  explorer rows and in an editor tab's header.
- EDIT-023 table (src/editor/csv.ts, CsvTable.tsx, EditorPane.tsx): a .csv or .tsv tab opens as a table with a
  Table / Source switch. The separator is worked out from the first rows (comma, semicolon, tab, pipe; a .tsv
  name wins a tie for tab; nothing fits means comma), a leading byte-order mark is dropped, and a quoted field
  holding separators, line breaks or "" stays one cell. The first row is the header; the grid follows the open
  text live; at most 2000 rows are drawn with a note that the source view has them all. A search hit in the
  file switches to Source to show the hit.
