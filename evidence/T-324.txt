WHAT WAS BUILT
- src-tauri/src/tray.rs: CLOSE_TO_TRAY_FIELD = "closeToTray" (off by default), CLOSE_EXPLAINED_KEY =
  "tray.closeExplained"; close_hides(os, settings, quitting): Windows only, only a real `true`, never
  while a quit is under way; explain_due(stored): the first-time explanation is owed until the key is
  set; on_close_requested(app) -> bool: with the option on it hides the main window, tells the dot model
  the window is hidden (so the next agent event lights the dot), shows the once-only explanation
  ("Kolux is still running — the window went to the tray...") and answers true so lib.rs calls
  prevent_close; otherwise false and the close goes through. quit() now sets a QUITTING flag before
  app.exit(0), so Quit from the tray is never intercepted and still reaches the RunEvent::Exit step that
  kills every pane and child process (Terminals::kill_all). Ping::UsageAlert added.
- src/settings/notifications.ts: CLOSE_TO_TRAY_FIELD and readNotifications().closeToTray (true only when
  saved as true). src/settings/NotificationsPage.tsx: the switch "Closing the window keeps Kolux in the
  tray" (Windows only; the agents keep running; Quit from the tray icon stops everything).
- src-tauri/src/notifications.rs: show_plain is pub(crate) for the explanation toast.
- USAGE 009 rule: usage_alert_send pings the tray (Ping::UsageAlert) before showing its toasts, so a
  hidden window gets the dot even when the system holds the toast back (patch, below). Judgment call:
  an alert the user switched off (usage-alerts preference or master switch off) is not "held back" and
  puts no dot; src/usage/alerts.ts is untouched.

LIVE PROOF PENDING (batched) — steps for the proof lane, once the patches are in main (Windows)
1. Settings > Notifications: the new switch is off. Click the window's close button: the app exits as
   before (process gone).
2. Switch it on, click close: the window disappears, the process stays alive, the tray icon is present,
   and a notification "Kolux is still running" appears. Close again later: no second notification.
3. While hidden, let an agent finish: the tray dot lights. Tray > Open Kolux: the window and the dot clear.
4. Tray > Quit with the option on: the app exits and every pane's child process is gone (check with
   Task Manager / `tasklist` for the shells that were running).
5. While hidden, drive an account over 80% (or hold a usage alert back in the system's notification
   settings): the tray dot lights.
