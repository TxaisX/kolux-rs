LIVE PROOF PENDING (batched) — steps for the proof lane, once the patches are in main (Windows)
1. Settings > Notifications: the new switch is off. Click the window's close button: the app exits as
   before (process gone).
2. Switch it on, click close: the window disappears, the process stays alive, the tray icon is present,
   and a notification "Kolux is still running" appears. Close again later: no second notification.
3. While hidden, let an agent finish: the tray dot lights. Tray > Open Kolux: the window and the dot clear.
4. Tray > Quit with the option on and no unsaved file: the app exits and every pane's child process is
   gone (check with Task Manager / `tasklist` for the shells that were running).
5. While hidden, drive an account over 80% (or hold a usage alert back in the system's notification
   settings): the tray dot lights.
6. (FIX-1) Option on, an editor tab with unsaved text: click the window's close button. Expected: the
   window hides to the tray with NO unsaved-changes question (nothing is lost; Kolux keeps running).
   Tray > Open Kolux: the unsaved text is still there.
7. (FIX-1) Option on, unsaved text: File > Exit. Expected: the unsaved-changes question appears (the
   window does not hide); Keep working -> still running, window on screen; Quit without saving -> the app
   exits and the shells are gone.
8. (FIX-1) Option on, window hidden in the tray, unsaved text: Tray > Quit. Expected: the window comes
   back with the question; Keep working leaves it on screen (a later close button hides again, since the
   quit flag was consumed); Quit without saving exits with every pane's process gone.
9. (FIX-1) Option on, then switch to a build without the tray feature (or a failed install, see the diag
