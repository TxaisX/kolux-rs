T-136-a (USAGE-009 usage alerts; USAGE-010 was built in T-135)

Lane profile, default window 1400 x 880. Real Codex figures were 0 % used, so the figures were set
through the dev-only window.__koluxUsage hook, reset time about 3 hours ahead. Each step was read
back from Windows' notification history (in a dev build Windows files the toasts under PowerShell's
app id), counting only "usage alert" toasts:

  Codex 5-hour 70 %                          0
  82 %                                       1   80 % alert
  84 %, 90 %                                 1   nothing more in the same window
  page reloaded, 88 %                        1   the fired record is in state.db
  97 %, 99 %                                 2   95 % alert, once
  new reset time (+5 h), 30 % then 81 %      3   80 % alert again
  Claude first seen at 97 %                  5   80 % and 95 % together
  Claude weekly 99 %, no reset time          5   none
  Settings > Notifications switch off,
    Codex 96 %                               5   none
  switch on again                            6   the 95 % alert that was due
