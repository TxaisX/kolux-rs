== finding ==
At 18:04:25 the hook script was rewritten by another Kolux RS instance started on this machine (another lane's app, with the
older template that discards the answer): every Kolux RS build shares ~/.kolux-rs/agent-hooks/, and the last one to start wins.
The proof above was taken after relaunching this app (18:09:22 rewrite, header checked before each run). After the lanes merge
all builds carry the same template, so this only bites while several builds run side by side.
