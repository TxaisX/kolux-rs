WHAT THE USER NOW SEES (once the two patches below are applied on main)
- A shell pane where the user typed `claude` (or `codex`) by hand: within about 5 s the Agents screen
  switches that session from the terminal to the chat thread with its composer; `exit` in claude puts
  the shell offer (terminal, no switch) back.
- An orchestrator worker or a typed-command session (panes Kolux started no program in, so they always
  got the shell offer before): chat once their agent is in front, terminal again when it ends.
- A launch whose program changed (claude exited inside its pane, codex typed after it): the chat
  follows codex, not the launch record.
- A hand-started session's conversation is read from the agent's documented session file location
  (Claude: <config>/projects/<folder>/<session>.jsonl, Codex: <home>/sessions/YYYY/MM/DD/*.jsonl), the
  pane's folder first, then any folder written since the agent was first seen (the shell may have moved).
