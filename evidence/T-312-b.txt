T-312-b: ORCH-061 runtime browser commands for agents, page leases (one holder at a time owns a
page placement; pages opened under a lease close when it is released).
lane/browser from c2e9b2f5 · 2026-10-20 · Opus 5.5

What was built
- src-tauri/src/browser_lease.rs (pure, unit-tested): the app's one lease table, in memory for
  the app's run. A lease is a named placement held by one holder; acquire refuses a placement
  someone else holds (naming them), the holder asking again keeps it; only the holder places pages
  under it or releases it; release hands back the pages still open so the caller closes them;
  prune drops pages closed by hand; names are trimmed, non-empty, at most 80 characters.
- src-tauri/src/browser_cli.rs (runtime commands, reach the app through the existing browser arm):
  - `tab lease --lease <placement> [--holder <name>]`: takes the placement (code "blocked" when
    another holder has it).
  - `tab create ... --lease <placement>`: takes the placement first (refused before any page opens
    when someone else holds it), opens the page and records it on the lease; a lease taken only
    for a page that never opened is given back.
  - `tab release --lease <placement> [--holder <name>]`: frees it and closes every page opened
    under it (waits up to 5 s for the tabs to go; "not_found" when nothing is held, "blocked" when
    another holder asks).
  - `tab leases`: every lease with its holder and still-open pages.
  - `tab list` / `tab current` rows carry "lease" for a page placed under one.
  - The holder is `--holder`, else the Kolux terminal the call came from (its key is checked by
    the app), else "cli".
- src-tauri/src/browser.rs: the lease module line.
- Shared files as patches (apply after browser-app070-update.rs.patch and
  browser-T-239-b-cli.rs.patch): evidence/browser-T-312-b-cli.rs.patch (help line for the three
  commands and --lease on tab create), evidence/browser-T-312-b-local_cli.rs.patch (agent-context
  summaries for the three commands; without it cli::local_cli agent_context test fails on
  "tab lease has no summary").
