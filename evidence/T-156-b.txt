Deliberate simplifications (ponytail; each named in the code)
- The starts-with split is not quote-aware; a `;` inside quotes also splits, which can only make a rule ask more.
- The regex refusal reads the pattern text, not the parsed syntax; an unknown escape counts as one character and a
  group counts as overlapping anything (it can only refuse more).
- A project is told from the hook's cwd by text prefix against the scope's root and `dirs`; the page stores the
  project's workspacesDir in `dirs` when it saves the first thing for that project. A relative workspacesDir
  outside the root is not resolved (it never matches), so such worktrees fall under "all projects".
- Rules are compiled on every PreToolUse (a handful of small expressions with a size limit); no cache.
