BUILT
- src/editor/diagrams.ts (new), no new npm dependency:
  - Locked diagram host: drawDiagrams() swaps each mermaid code block in the preview for an iframe with an EMPTY
    sandbox attribute (no scripts, no same-origin) whose page carries a policy of default-src 'none', inline styles and
    data pictures only; the SVG is first cleaned (DOMPurify SVG profile, scripts, foreignObject, links, handlers
    removed). The frame keeps the picture's proportions from its viewBox. A diagram that fails keeps its code block and
    gets a one-line "Diagram could not be drawn" note.
  - mermaidConfig(dark): strict security level, no HTML labels, theme "dark" with light-on-dark variables, "neutral"
    for a light page.
  - Maths: extractMath swaps $x$ (not money like "$5 and $10", not code spans or fences, not escaped dollars) and
    $$ blocks (one line or many) for plain placeholders before the markdown parser sees them; restoreMath puts the
    renderer's markup back, or the author's own text (escaped) when there is no renderer or the TeX is bad.
  - Pluggable hook: setRenderers / getRenderers / watchRenderers, and loadRenderers() which imports
    src/editor/diagramLibs.ts only if that file exists (import.meta.glob), so the app builds the same without it.
- src/editor/PreviewPane.tsx: renders through renderNote (maths out, markdown, maths in), redraws when the renderers
  arrive, and draws diagrams after each render. editor-extras.css: frame, error note, maths styles.
- Without the libraries nothing changes for the reader: fences and dollar text show as written.
