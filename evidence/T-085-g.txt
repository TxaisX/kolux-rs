T-085-g · AUTO-011 the self-closing run tab · lane/automations from 8cd8172d · 2026-10-19 · Claude Sonnet 5.5

What the user now sees (once the App.tsx patch is applied): an automation run's agent opens in a
background tab; when that agent exits, the tab closes by itself, once. If the user clicked in the
tab or typed in it, or pinned it, it stays. A tab a run did not open (a shell, an agent the user
started, a run's setup or default tabs) is never touched. A failed run closes its tab too: the card
says the tab shuts when the agent exits and names only the click/type exception; the end of the
output and the reason stay on the Runs page (AUTO-014).

Design (card AUTO-011): no Rust change. The pane a run opened is already known to the app
(runPanes, set when the start request returns the pane key). The exit is already announced to the
app ("terminal-exit" with the terminal id; ptys maps pane key to terminal id). So the whole
decision sits in the page:
- src/automations/runTab.ts: openRunTab / touchRunTab / forgetRunTab / runTabEnded (close | keep |
  ignore, and the tab is forgotten with the answer, so it is once) / paneOfTerminal / typedInRunTab.
- A click is the pane's existing mouse-down (onFocus). Typing is a real key event inside the focused
  pane while that pane is a followed tab; Kolux's own writes (the opening prompt typed in by the app,
  terminal replies) are not DOM key events, so they never count as the user.
- Pin counts as the user claiming the tab (not on the card; a conservative reading).

Patch for the merge resolver (one, no terminal.rs patch needed):
- evidence/automations-T-085-g-App.tsx.patch: import runTab; runTabs ref beside runPanes; start
  handler registers the run's pane; dropPanes forgets keys; the terminal pane's onFocus marks
  touched; one effect listens for keydown (capture) and "terminal-exit" and calls the existing
  cli.current.dropPane(key) when the verdict is close. `git apply --check` passes on this tree (HEAD
  after STEP 0). With the patch applied: pnpm exec tsc --noEmit exit 0 (g-tsc.log), vitest
  src/automations 6 files / 59 tests passed (g-vitest.log). The target file was then checked out so
  the commit holds only the patch.

Tests (src/automations/runTab.test.ts, 8, all pass):
- an untouched run tab closes when its agent exits, once (a second exit event closes nothing)
- a tab the user clicked or typed in stays open (and touching again returns the same state)
- a pinned run tab stays open
- a tab no run opened is never followed or closed
- touching one run tab leaves another run's tab to close
- a tab closed or replaced by other means is no longer followed
- the exiting terminal is matched to its pane, an unknown terminal to none
- only keys inside the focused pane, when it is a followed tab, count as typing

Gates: Rust unchanged, so cargo build/clippy/test skipped (the last Rust gates are T-085-h's:
26/26 automations::tests, clippy clean). tsc 0, vitest 59/59, plan-check and firewall below.
