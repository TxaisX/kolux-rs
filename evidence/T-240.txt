Coordinator ruling followed: Chrome on Windows (v127+) seals its cookie store with app-bound
encryption that only Chrome's own elevation service unwraps. Kolux does NOT open, copy, decrypt or
read Chrome's profile, call that service, inject into Chrome, run elevated or attach to a debug port
on the user's profile. "Import from Google Chrome" is a guided export: the user exports the sites
they want to a cookies.txt file from inside Chrome with a cookies.txt export extension, then picks
that file; the file importer below does the rest.

What changed
- src-tauri/src/browser_cookies.rs: parse() now takes either shape: a file starting with [ or { is
  the JSON list (unchanged, now parse_json), anything else is a Netscape cookies.txt file
  (parse_netscape): one cookie per line, seven tab-separated fields (domain, include-subdomains
  TRUE/FALSE, path, secure TRUE/FALSE, expiry seconds with 0 = session cookie, name, value);
  "#HttpOnly_" before the domain marks HTTP-only; other # lines and blank lines are skipped; CRLF
  and a leading BOM are fine. Each line goes through the same checks as a JSON entry (name token,
  value without control characters or semicolons, host name, path starting with /, expiry not
  past). A malformed line is skipped and counted, named by line number and reason only (never its
  value; ten reasons kept, count whole). include-subdomains TRUE gives ".host", FALSE "host". The
  Google rule (BROW-029) applies the same way. An empty file, a file of comments only, and a file
  whose every line fails are refused with the reason. The import command, the size cap and the
  per-site replace with roll-back (apply) are unchanged; cookie values go only to the tab's engine
  store (wry set_cookie into WebView2's cookie manager for the tab's profile) and are never logged.
- src/browser/cookies.ts: CookieSource, IMPORT_SOURCES (Import from Google Chrome..., Import from a
  file...), CHROME_STEPS (the three guided steps), pickerFor(source) (Chrome: cookies.txt; file:
  cookies.txt or JSON).
- src/browser/BrowserPane.tsx: the toolbar's Import cookies button opens a small menu in the pane's
  flow (Chrome first, then a file, then the Google note); Chrome shows the steps with "Choose
