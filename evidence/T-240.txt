What changed
- src-tauri/src/browser_cli.rs: DEVICES starts with the seven toolbar presets (Mobile S 320x568,
  Mobile M 375x667, Mobile L 425x812, Tablet 768x1024 at 2x with the phone identity and touch;
  Laptop 1024x768, Laptop L 1440x900, Desktop 1920x1080 at 1x), PRESETS = 7; the old 1366-wide
  "Laptop" of `set device` is replaced by the compat one. emulate(id, w, h, scale, mobile) is the
  shared tail of `browser.viewport` / `set device` (state into EMU first, then relayout, then the
  page script; a size that took but an identity that did not is reported as "partial"); preset(id,
  name) is the toolbar's Viewport Size: None / "Default" clears the viewport, puts the plain
  identity back and resets zoom to 100 %. The preset holds through loads and redirects because the
  load hook re-sends EMU's state at every load's start (T-242).
- src-tauri/src/browser_cookies.rs (new): BROW-028's file path. parse(text, now): the file must be
  a JSON list, not empty; each entry needs name (a cookie token), value (no control characters or
  semicolons), domain (a host name, lowercased); optional path (must start with /), secure,
  httpOnly, sameSite (strict | lax | none | no_restriction | unspecified), expirationDate | expiry |
  expires (seconds; an expired entry is skipped); bad entries are skipped and named (count whole,
  ten reasons kept); a file with nothing usable is refused with the reasons. BROW-029: google.com
  and its country forms (google.de, google.co.uk, google.com.au, any host under them) are left out
  and counted; youtube.com, googleapis.com, googleusercontent.com are kept; nothing of Google's is
  deleted. cookie_of builds the engine's cookie (session cookie without an expiry); by_site groups
  entries in the file's order; apply(page, entries, report): per site, the tab's cookies for that
  domain are deleted and the file's set; a failure puts the site's old cookies back, removes what
  was set, and stops with the site named. FILE_MAX 4 MiB.
- src-tauri/src/browser.rs: `cookies` module; browser_open reads the sealed `httpProxy` setting
  (secrets::read_setting; a secret store that cannot be read leaves the tab unopened) and
  proxy_of() turns it into the engine's proxy_url: empty means the system's own proxy (OD-18),
  http:// or socks5:// with a host is applied to every tab of every profile, anything else refuses
  the tab (it stays closed rather than going direct) with a message that never carries the value
  (SAFE-026). browser_viewport(id, name) and browser_cookies_import(id, path) commands (async: the
  page answers on the main thread); the import reads the file (size cap), parses with the clock,
  then applies to the tab's own engine, so a profile's import lands in that profile's cookie store.
- src/browser/BrowserPane.tsx: VIEWPORTS (Default + the seven), a native select "Viewport size" in
  the toolbar's right group (browser_viewport; errors in the note), and an Import cookies button
  (plugin-dialog open, JSON filter, browser_cookies_import; the note says how many cookies for how
  many sites came in, what was skipped and why, and how many Google sign-ins were left out).
  CookieReport type.
- src/browser/browser.css: select.viewport rules; under 360 px pane width the select and the
  cookies button are hidden (the address bar keeps its room).
- evidence/browser-T-240-lib.rs.patch (new): registers browser::browser_viewport and

  browser_probe), so it applies before or after browser-T-242-lib.rs, browser-T-238-b-lib.rs and
  browser-T-159-lib.rs.
