What is built (core of the card: the on-the-spot answer)
- src-tauri/src/prompt_answer.rs (new, hooks lane): the answer path over T-129-d's ORCH-056 grid scan.
  - choices(prompt): the answers the menu on screen takes, top to bottom, from the menu's own shape:
    the highlighted option (❯ › ● ◉) takes Enter (the key VIEW-025's answer_keys already uses for Claude),
    a numbered option "N." / "N)" takes its number, a [y/n]-style tail takes y or n. A menu with any option
    the scan cannot key (an Accept/Reject toggle, an unnumbered option that is not highlighted, two options
    with one number) offers nothing: the Inbox then shows Answer in Code only.
  - decide(prompt, alive, expected, choice): Gone when the pane has no running terminal, NoPrompt when the
    screen shows no menu, Moved when the prompt on screen is not the one the user answered, Unsure when the
    choice is not one of the menu's keyed options; otherwise the Choice. Each refusal has a sentence.
  - Once: one answer per reading of the screen (terminal, output cursor, pending text, prompt text); the
    same reading is never typed into twice; a write that failed frees it for another try.
  - commands prompt_read(pane_key) -> {prompt, choices} | null and prompt_answer(pane_key, text, choice)
    -> Choice | error sentence. Both resolve the pane's live terminal through terminal.rs attached() (APP-052:
    a session of this run that has not ended), read FRAME_LINES of newest output, scan through
    prompt_scan::live_prompt (restored scrollback skipped, memoised), type the keys with terminals.write,
    and mark a pane whose hooks report nothing as working through status_inband; a hooked pane is left to its
    hooks (its next hook event moves it).
- src-tauri/src/prompt_scan.rs (T-129-d module, additive only, no behaviour change): Prompt gains
  options: Vec<String> (the option lines, top to bottom, borders stripped) and pub fn live_prompt(terminal,
  read) wraps the shared scanner; the prompt_scan command uses it. Cross-lane edit by coordinator default
  (see kolux-rs-after.md row; Txais may overrule).
