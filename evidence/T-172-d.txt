Coordinator default (Txais may overrule, after-list row): worker-start never runs a setup script itself.
It asks the window, over the notice it already sends, to run the trust question and the setup once,
waits for the window's answer, then starts the agent or fails at the setup stage.

  app has no pending line to type a second time; mail itself stays in the store for check.
