T-198-b · SKILL-031: kolux skills install and kolux skills update through the community skills installer (lane/skills from 8d76ce1f)

What was built
- src-tauri/src/skills/cli_install.rs (new): every rule of the two commands, on top of installer.rs (the commands, the Windows command-script shim, the forwarded-shell refusal, the swappable Installer) and skill_delete::lock.
  - install: --skill a,b (comma list) or --all, never both; neither returns the list on offer ("name some with --skill a,b, or take them all with --all"). An unknown skill is not_found and lists the skills. Names holding shell syntax are refused.
  - --agent a,b: a comma list with no blanks, Kolux ids or installer names; universal aims only at the shared folder. With no --agent the detected agents are used, minus the ones the shared folder already serves (codex, cline, kimi, pi), plus universal. Nothing detected and none named: "name an agent".
  - Global unless --local. --dry-run prints the exact command and starts nothing. A real run is unattended (agent list + -y).
  - --json on a real run is refused (json_refusal); it is allowed with --dry-run and with the listing.
  - The installer's exit status is passed on: a non-zero status is the error installer_failed with exitCode and the log in its data and hint; a missing Node.js is installer_unavailable with the plain message.
  - update: the same flags except --agent; only skills that are installed and that update::check says the installer may update (recorded, unchanged, out of date); installed but kept gives not_updatable, not installed gives not_installed.
  - Both take skill_delete::lock for the whole run; Busy is a plain refusal.
- skills.rs: one line, pub mod cli_install; update.rs: fresh() made pub.
- The route into the CLI belongs to the CLI lane's files, so it is a patch pair: evidence/skills-T-198-b-local_cli.patch (command rows, summaries, run and text arms, skills_install(), one test) and evidence/skills-T-198-b-cli.patch (the local switch, --json passed through to the two commands, the help lines). Verified: both apply cleanly to this checkout, and with them applied cargo test --lib (skills::cli_install, local_cli::, cli::tests: 85 passed) and clippy -D warnings are clean. The files in the commit are the checkout's own, without the patches.

Tests (cargo test --lib skills::cli_install, 9, all with a fake installer, no real process)
- dry run prints the unattended command for the detected agents and runs nothing; skill + all is an error and neither lists the offer; unknown names and shell syntax refused; agent comma list and universal; no detected AI asks for an agent; --local drops -g; update takes only installed, updatable skills and no --agent; a real run goes through the installer under the lock, passes the exit status on, reports an installer that cannot start, and is refused with the lock held; --json refused on a real run only.
