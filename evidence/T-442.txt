T-442 timing proof (2026-10-13, lane reliability dev app)
A stand-in git.exe first on PATH waits 3 s and then runs the real git (slowgit.rs, throwaway).
Each trial starts the slow command, waits 300 ms, then times one terminal_write (the call every keystroke makes).
git_changes (files.rs, not in this card) is left a plain command as the control: it still runs on the window's thread.
An earlier run, before scm.rs's other commands became async, had scm_summary as the control: terminal_write waited 27924 ms and 30413 ms behind it.
