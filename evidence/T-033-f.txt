  check-ignore already answers a folder that holds a tracked file as "not ignored" (proved on git

  recursive, only when it exists so a missing folder cannot break the watch); its `exclude` file
  forgets that worktree's answers and reads once; nothing else in info/ counts.
- The Ignores doc comment now names the tracked-file rule and both exclude files.
