TERM-088 Selecting text in mouse-capturing programs
- Shift-drag selects over a program that takes the mouse (xterm forces selection with Shift; the pane's right-click
  already follows the same rule). A plain drag over such a program now shows once: "This program uses the mouse. Hold
  Shift while you drag to select text." (mouseFeel.ts dragWantsHint / SHIFT_HINT, TerminalPane drag listeners).
- After a restart the pane replays its saved history, which holds the mouse-on codes of a program that is gone; unless
  the terminal service still runs that program (attached), the modes it left on are turned off right after the replay
  (resetAfterExit), so a plain drag selects again in the new shell. A program that dies while the pane is attached is
  covered by the reset at exit (ACCT-060).
TERM-089 Mouse wheel scroll speed
- Normal 1.15 (text.ts default, one line), fast 5 (already), full-screen 1 (inputPrefs FULL_SCREEN_SCROLL start).
- xterm sends one report (or one arrow key) per wheel event inside full-screen programs whatever the setting, so the
  full-screen setting scaled nothing and fast bursts queued in the program. mouseFeel.ts WheelDrain counts whole notches
  (100 px, or 3 lines, per notch; trackpad steps add up), scales by the full-screen setting (times fast with Ctrl/Alt),
  sends the first notch at once and the rest at most once per frame, capped at twice one notch, dropping the excess.
  TerminalPane hands each report back to xterm as a one-line wheel event, so xterm still does the encoding.
TERM-091 Scrollback length
- Default row limit and trimming from the oldest end: the scrollback setting (default 1000 rows) and the memory
  profile size (ACCT-059) are xterm's scrollback, which drops the oldest rows.
- A pane hidden by a tab switch keeps its row with a buffer marker (it follows the row as old rows are trimmed) and
  scrolls back to it after it is shown and sized again; a pane at the bottom stays at the bottom.
