  lists files of the session's folder (names with spaces are quoted); in a Codex chat "/" lists commands and "$" lists skills. Up to 8
  lines, best matches first (exact, prefix, then fuzzy, then description). Arrow keys move, Tab puts the choice in the text, Enter runs a
  command or skill (a file is only inserted), Escape closes it for that word. A name that is both a command and a skill shows once,

  Fast On or Off where offered. Choosing a Claude model sends a "/model <name>" line and the list says "Sent, not confirmed yet" until the
  chat reads the agent's "Set model to ..." line back, then "Confirmed". Typing a bare /model focuses the list instead of sending.
  Claude's effort and fast mode, and Codex's model and effort, cannot be changed from the box: effort/fast are saved for the next launch
  (labelled "At next launch"), Codex's pickers are reached by switching to the terminal (the note says so). Controls are off while the
  agent works or has no terminal.
- CHAT-026: Ctrl or Cmd with plus, minus or zero while the chat has focus zooms the chat text from 0.8x to 1.6x in tenths; zero resets.
  Session only. (Needs evidence/chat-T-334-App.tsx.patch so the terminal zoom does not take the chord first.)
- CHAT-008: the newest 300 messages show; "Load earlier messages (N more)" at the top adds 200 older ones with the reading position kept;
  it disappears at the beginning of the conversation.
- CHAT-021: pasting an image (clipboard image, saved by the same command the terminal uses), dropping files on the chat, or the + Attach
  file button adds a chip above the box (thumbnail for pasted images, name, remove x, click a thumbnail for a full-size preview,
  "Preview unavailable" if it cannot be drawn). 5 at most. Send waits while an image is still saving; a failed save says why. On send
  the paths follow the message text on a line of their own. Agents other than Claude, OpenClaude and Codex refuse a pasted image
  with a note.
