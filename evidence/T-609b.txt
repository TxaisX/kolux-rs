T-609b · The sidebar's changed-file count, from a real source, on by default · lane2/product-ux-2 · 2026-10-31
Proved in the Linux cloud sandbox (node 22, vitest 4.1.11). Nothing was run on Txais's PC.

THE BUG UNDER IT
src/projects/ProjectsPanel.tsx fed CardFacts.changed from RowInfo.changed, which is the time the row's state last
moved (App.tsx rowStates: { state, changed: Date.now(), pr: null }). Anyone on Detailed, or ticking Changed files,
saw a card line like "1761870000000 changed files".

WHERE THE REAL COUNT IS
The back end's scm_status (src-tauri/src/scm.rs) is git status for one worktree: staged, changed, untracked and
conflicted lists. The Source Control panel and the Inbox detail (InboxView.tsx) already read it; the Inbox detail
sums the lists. cleanup.rs scan_row counts `git status --porcelain` lines too, but that scan also checks merges
and idle days, so it is heavier. No count was kept per worktree in the sidebar.

WHAT CHANGED
- src/look/cardChanges.ts (new): changedCount(status) counts each path once over the four lists; CardChanges
  reads one workspace at a time, keeps each answer 10 s, keeps the last count when a read fails, and redraws only
  when a count moves; useCardChanges reads every listed workspace while the cards show the count, again on window
  focus, and at once for the workspace an agent just finished in (status/finished.ts onFinish). The pointer
  entering a card reads that one too (for Compact's hover).
  ponytail (noted in the file): scm_status is the panel's foreground read and returns the capped file lists; a
  count-only background command in Rust would be lighter for many workspaces.
- src/projects/ProjectsPanel.tsx: the card's facts take cardChanges.countFor(w.path); RowInfo.changed stays the
  row's time (Smart sort, the palette's age) and is no longer read as a count.
- src/look/cards.ts: PRESETS.default is ["status", "agents", "changes"]; the Default note reads "Status, an agent
  summary and the changed-file count under the name."; the header comment says so.
- Tests: src/look/cardChanges.test.ts (new); src/look/cards.test.ts and src/look/clickThrough.test.ts follow the
  new Default (Default minus the summary is now custom; Default minus summary and count is Compact; from Detailed,
  unticking the pull request and the note is Default).
