LIVE PROOF PENDING (batched). Click-through for the batched live run (a throwaway test repository):
1. Tasks, open an open issue: under the timeline there is "Close as completed", Close issue, a comment
   box and Comment.
2. Type a comment, Comment: the box empties and the comment shows on GitHub.
3. Choose "Close as duplicate", type 99999, Close issue: "There is no issue #99999 in <repo>." and the
   issue is still open on GitHub (nothing sent).
4. Type the number of a pull request: "#N in <repo> is a pull request, not an issue."
5. If the repository has issues with similar titles, they are offered under the box; click one, Close
   issue: the state badge turns closed, the list row turns closed, GitHub shows "closed as duplicate of".
6. Reopen issue: the badge and the row turn open again; GitHub shows it reopened.
7. Choose "Close as not planned", Close issue: GitHub shows it closed as not planned.
