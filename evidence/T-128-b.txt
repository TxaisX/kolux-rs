T-128-b · ACCT-050 on Unix: the foreground process group names the agent; Ctrl-Z hands the pane back · 2026-11-01 · lane5/T-128-b
Built and proven in the Linux cloud container (4 CPUs, /dev/ptmx present, bash 5, no desktop). The app cannot be launched here.

WHAT THIS UNIT IS
T-128-a built the recognition (src-tauri/src/foreground.rs) on Windows by process tree and on Unix by the terminal's
foreground process group (PtySession::foreground_group -> portable-pty process_group_leader -> tcgetpgrp). The Unix branch
of `front` (foreground.rs, cfg(not(windows))) had never been compiled or run: every ACCT-050 test was table-driven or
Windows-only. DT-C41 parked the Mac/Linux half. This container is Linux, so the Unix branch is compiled and checked here
for the first time, against a real PTY and a real interactive shell. No product code changed.

WHAT CHANGED
- src-tauri/src/foreground.rs, tests module: two cfg(unix) tests and three small helpers (unix_pane, front_within,
  end_unix_pane). The pane is `bash --norc --noprofile -i` spawned through PtySession::spawn at 80x24 in a fresh temp
  folder; the stand-in agent is a link named `claude` to /bin/sleep, so the foreground process's command line reads
  `./claude 30` as a native Claude binary's would (a `#!/bin/sh` script would read `/bin/sh ./claude`, which is sh, not
  Claude). The poll is the one `poll` does: front(pid, session.foreground_group()), every 100 ms.
  1) acct_050_unix_an_agent_typed_into_a_shell_is_in_front_until_ctrl_z_hands_the_pane_back:
     right after start the foreground group is the shell's own (Some(pid)) and front is Shell; type `./claude 30` ->
     Agent("claude") within 3 s, in a group that is not the shell's; Ctrl-Z (0x1A) -> Shell within 2 s and the foreground
     group is the shell's again; `fg` -> Agent("claude") again; Ctrl-Z -> Shell.
  2) acct_050_unix_a_background_job_is_never_the_foreground_agent: `./claude 30 &` -> front stays Shell, the foreground
     group stays the shell's, and pgrep confirms the job is running under the shell.
  Both end the job with `kill -9 %1`, kill the session and remove the folder.
- PLAN.md: the T-128-b line carries a BUILT/REST note and stays unticked (the desktop acceptance run is DT-C41's remainder).
