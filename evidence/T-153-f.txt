Card rules (VIEW-099)
- Manage Sessions also ends sessions the daemon holds that no window owns: built (list + End N + per-id end).
- The confirmation is left out only if Kolux has confirmed the session already ended: the fresh read before asking drops ended ones; an id the service no longer has answers Ok(false) with no question.
- Agent-owned sessions are never offered: built (agent flag, refused server side too).
- Until the window has loaded its workspaces, no session is shown as attached: nothing listed before loaded, and the backend returns nothing while the window is still taking its terminals back.
