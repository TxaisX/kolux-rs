1. Open a Claude tab in a project folder and let it settle (the user's own tab).
2. From a coordinator pane: kolux-dev orchestration worker-start --spec "say hi" --agent claude --worktree current --setup skip,
   with the window's start held back so the start ends "unknown" at the timeout. Expect: the receipt says the start timed out
   and that worker-show / worker-stop find its session if it starts later.
3. Let the window start the agent late (inside ten minutes); worker-show --dispatch <id>. Expect: terminal = the new tab,
   lateStamp true; the user's tab is never the one named.
4. worker-stop --dispatch <id>. Expect: only the worker's late tab ends; the user's tab stays open and responsive.
5. Normal case (no hold-back): the receipt names the new background tab (terminals[0].id), worker-show the same, worker-stop ends only it.
6. Negative: window not stamping -> the start ends "unknown" with no terminal recorded; a later worker-stop leaves the user's tab alone.
A-D. Stop (or release) the dispatch before the late agent comes up; after it comes up worker-show says
   "<id> was already stopped when its agent came up late ... next: worker-release", --json lateWorker / lateStamp true / lateAfter "stopped";
   worker-release closes the late tab (output saved) and a second release on a released row closes it instead of "already released".
