WHAT WAS BUILT (new shell-owned src/shell/tabTitle.ts, 4 vitest in tabTitle.test.ts)
- Tooltip: every terminal tab's name span carries data-tip = the full title (STAT-052's Tip shows it ~200 ms after the
  pointer rests; the tab itself stays clipped by CSS at 160 px). When the tab shows something other than the full title,
  the tip reads "<full title> · shown as <text>".
- Generated titles: a setting, generatedTabTitles, off by default (generatedOn is true only when the field is exactly
  true). On, a terminal pane with no name of its own shows a short generated name: the worker's task label when it has
  one (ORCH-066 / T-129-d), else "<agent word> · <branch, else cwd folder>", clipped to 24 characters with an ellipsis.
  A name the user typed (p.title, the rename field) always wins; editor, browser, preview, diff and changes tabs are
  untouched. Off, tabs keep what the program set (tabName unchanged). The Settings switch itself is T-124-b's (hooks
  lane): this module is the title source it reads (GENERATED_TITLES_FIELD, generatedOn, generatedTitle, tabText, tabTip).
- Priority with the sessions lane's T-119-c (64e26b2a, not on main): tabText takes the full title from tabName, so when
  T-119-c lands (tabName with the followed title from shellMarks) the tooltip and the off-state text carry it without a
  change here; the own-name-wins rule is the same in both.
