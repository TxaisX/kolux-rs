Ceilings and partials (also on the after-list)
- Capture: entries belong to the document; a page navigated away from before console/network/stop
  pulled them loses them (the recorder lives in the page, not in the engine).
- set headers / set credentials cover fetch and XMLHttpRequest, not top-level navigations or
  <img>/<script> loads (no request interception in Tauri's public API on Windows).
- set media changes matchMedia answers and the document's color-scheme; CSS @media rules written in
  stylesheets are not re-evaluated (no engine-level emulation API).
- viewport --mobile sets maxTouchPoints and the viewport only; the user-agent string is not
  switched (same blocker as BROW-025 / T-239-b).
- BROW-067 candidates are the addresses the workspace's terminals printed that listen now; a
  server started by a process of the workspace that printed nothing is not found (needs the pane's
  process tree: AFTER). The recogniser works on each output chunk; an address split across two
  chunks is missed.
- The intercept hold is per page: a held request is released when intercept is disabled or the
  tab closes (the page goes with it).
