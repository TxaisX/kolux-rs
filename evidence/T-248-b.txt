## What was built (code pointers)

- src-tauri/src/tray.rs: the T-248-a model (Open Kolux / Quit, Windows+macOS only, left click opens
  on Windows, tooltip "Kolux DEV (<branch>)", the Dot) now drives a real tray icon:
  `install` (menu, tooltip, icon, click and menu handlers), `ping` (lights the dot only while the
  main window is hidden or minimised, read live from the window), `window_shown` (clears it),
  `open_window` (show + unminimize + focus + clear), `quit` (app.exit(0): the Exit step in lib.rs
  stops every pane and child process, the same path as File > Exit).
  The DEV marker and the amber dot are painted onto the app icon's own RGBA (`paint`), so no image
  decoding feature is needed; the DEV square stays when the dot version is swapped in (STAT-047).
  The branch of a development copy is read from the checkout's Git HEAD (`git_head_file`,
  `branch_from_head`; worktrees' `.git` files are followed).
- src-tauri/src/notifications.rs: `show` (every agent notification through the `notify` command)
  pings the tray first, so the dot lights even when the toast is blocked; the Notifications page's
  test button uses `show_plain` and never lights it.
- The real tray needs tauri's `tray-icon` feature. tray.rs gates it behind this crate's `tray`
  feature so the tree builds and tests with AND without the coordinator's Cargo.toml patch.
