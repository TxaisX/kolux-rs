Source (public docs only): https://hermes-agent.nousresearch.com/docs/user-guide/features/hooks (shell hooks:
top-level hooks: key in ~/.hermes/config.yaml keyed by event, entries command / timeout (seconds) / matcher;

profile, extra; stdout read as a decision; first-use consent per (event, command) kept in
~/.hermes/shell-hooks-allowlist.json as {"approvals": [{"event", "command"}]}, also --accept-hooks /
HERMES_ACCEPT_HOOKS=1 / hooks_auto_accept). https://hermes-agent.nousresearch.com/docs/user-guide/configuration
(state is profile-scoped through HERMES_HOME).
Built (src-tauri/src/agent_hooks/hermes.rs, hermes_tests.rs; wired in more.rs; MANAGED/apply via
evidence/hooks-T-121-2-mod.rs.patch, stat_004 via evidence/hooks-T-121-2-tests.rs.patch):
- Events hooked (13): on_session_start (ignored, idle), pre_llm_call -> working, pre_tool_call / post_tool_call
  -> working, pre_approval_request -> needs you (permission), post_approval_response -> working,
  on_human_input_request -> waiting (question), on_human_input_resolved -> working, post_llm_call /
  on_session_end / on_session_finalize / on_session_reset / agent_loop_stopped -> done.
- No YAML crate in Cargo.toml and none added: a marked-block LINE editor, not a YAML parser. Kolux's entries
  go in as blocks between "# >>> kolux-rs status hooks (... sum <16 hex>) >>>" and "# <<< kolux-rs status hooks
  <<<"; the begin line carries a sha256 prefix of the block's lines. Under each event the user already hooks,
  one block opens the user's own list; the other events go in one block opening the hooks: map; with no
  hooks: key, one block at the end holds the whole key. A block whose lines no longer match its sum (edited
  by hand), a lost end line or a stray end line: install AND removal refuse and leave the file alone.
  Shapes a line editor cannot join (hooks: {} on one line, hooks as a list, an event set on one line or as a
  map, two hooks: keys, a flow-style root) are refused, file untouched.
- Removal gives the user's file back byte for byte (CRLF and a missing last line break included); a file
  Kolux created goes; an emptied file stays empty. Command written as YAML '"<script path>"' (forward slashes,
  quoted for the shell-style split). Hermes home: HERMES_HOME for the real home only; a scratch home keeps
  ~/.hermes inside it (as Grok's GROK_HOME).
- First-use consent: the docs give the allowlist file for approving without a prompt, so Kolux adds its 13
  (event, command) pairs beside the user's (an older Kolux path's pairs are replaced) and takes only its own
  out on removal (a file Kolux created goes). The status row says partial with a consent hint when the pairs
  are missing.
