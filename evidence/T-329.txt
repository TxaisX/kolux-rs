T-329 · CHAT-018 Stop interrupts the agent · CHAT-023 Allow or deny a tool permission in chat · CHAT-025 Links in chat open files and web pages
lane/chat from 2d14c7db, 2026-10-19. No Rust touched (cargo gates skipped).

WHAT THE USER CAN NOW DO
- CHAT-018: while the agent works, the button beside the message box reads Stop. Clicking it types Escape into the agent's terminal;
  any message still waiting to send (queued behind another, or half typed) is cancelled first and its waiting row goes, with the
  note "Stop cancelled the message that was waiting to send." A Stop within 700 ms of a send from the box does nothing (a
  double-click on Send never interrupts). While the agent is asking something in its terminal the button stays Send (disabled)
  and stopPane types nothing: Escape there would answer the question.
- CHAT-023: when a Claude or Codex hook says the agent asks to run a named tool, a card "Allow <tool>?" appears above the box with
  the command or detail, Allow and Deny (Claude: Enter / Escape; Codex: y / n), a dismiss cross (answer in the terminal; stays
  dismissed until the next prompt) and, for ExitPlanMode, Review plan (opens the app's plan review through the App.tsx patch, or
  shows the plan inside the card without it). Prompts are counted per pane from every hook event, so a second approval is its own
  card; a click on a stale card types nothing and says so. OpenClaude gets no card (its menu keys are not confirmed).
- CHAT-025: in the agent's replies, web addresses, `[label](target)` links, email addresses and file paths (with :line, :line:column,
  (line,col)) are links. A plain click on a web link opens a small choice (Open in Kolux / Open in your browser); Ctrl (Cmd on a
  Mac) takes the main choice, Shift with it the other. A file opens (in the editor through the App.tsx patch, else the system) only
  when the agent printed that path recently (its replies, plans, and the files its tools read or wrote, newest 200 messages); text
  the user typed never counts. Page anchors, unknown schemes, malformed file links and empty links are plain text. Email opens the
  system mail handler (open_external allows mailto).
