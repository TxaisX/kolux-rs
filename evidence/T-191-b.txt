- src/launch/teams.ts: the Agent Teams mode preference (settings key agentTeamsMode: off, the

  Teams" (id claude-agent-teams, per the COMPAT agents table; it runs the claude-teams subcommand). The entry is offered only with the mode on, Claude Code installed, the

  release, and the Kolux command line path off Windows/WSL) with the pure `teams_host_from`.
- Keybinding command: tab.newAgent.claude-agent-teams (already in the keys list on main) "New Claude Agent Teams tab", no key bound, comes
  from adding the entry to the keybinding agent list (src/keys/actions.ts is core's: hunk below).
  App.tsx already resolves tab.newAgent.<id> against the offered agent list, so the command opens
  the tab only when the entry is offered.
