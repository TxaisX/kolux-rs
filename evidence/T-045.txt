T-045 (SET-030 Accounts & keys flags sign-in trouble)

No real sign-in was used. Every screenshot was taken with stand-in programs named claude.exe and
codex.exe, compiled for this check and put first on the dev app's PATH. The claude stand-in answers
`auth status` from a throwaway credentials file (signed in as the made-up own@example.com while it
holds a "fresh" marker) and `auth logout` deletes that file. The codex stand-in rejects every
command line with a parser-style usage error and exit code 2. Two Codex accounts were seeded into
the lane's profile (kim@example.com with Kolux's settings file, lee@example.com with
`cli_auth_credentials_store = "keyring"`), with fake auth.json files; all were removed afterwards.
