T-089-c evidence (lane/orchestration from 4edd933), 2026-10-13

What lands in this commit (src-tauri/src/orchestration.rs, owned by this lane):
- release(): marks a settled worker "release pending" before anything is closed and hands back
  its live terminal handle; a worker still working is refused (dispatch_active, with the
  worker-stop command); a worker whose terminal is already gone is released at once; releasing
  twice answers the same (alreadyReleased); a kept (retained) worker can be released.
- release_done(): saved and closed -> released with the archive path; saved but not closed ->
  release unknown; save failed -> release unknown and the terminal is left open, with the reason;
  every unknown receipt names the retry (worker-release --dispatch <id>).
- write_archive(): the output goes whole to <data folder>/worker-archives/<dispatch id>.txt
  (the id is made safe as a file name).
- terminal_state(): release_pending / release_unknown are now real states, so worker-list's
  --terminal-state filter can find them.
- stop_warning(): worker-stop's receipt carries a warning whenever the process verdict is
  unverifiable ("the worker's process was kept alive ..."); stop() calls it, and the CLI calls
  it again after a failed kill.
- terminal_for(): a terminal command aimed at a worker with no terminal is refused by name
  (no_terminal) with the worker-read --source transcript way to read it instead.
- worker_show(): one worker's row plus waiting yes / no / unknown; "no" only when its terminal
  has ended, "yes" for an input or approval hook state on an open terminal, otherwise unknown
  (a quiet pane is never reported as waiting on nobody).
