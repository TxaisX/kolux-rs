WHAT CHANGED
- src-tauri/src/browser_cli.rs: the refusal table is gone; screenshot, full-screenshot and pdf take --path.
  capture(): screenshot = the engine's DevTools call Page.captureScreenshot (png or jpeg, the visible page);
  full-screenshot = Page.getLayoutMetrics then Page.captureScreenshot clipped to the whole layout (sides capped at
  16384 px); pdf = the engine's PrintToPdf straight to the file. The picture arrives as base64 and is decoded
  before it is written, so "bytes" is the decoded size. download(): the tab's next download is armed to the
  path, the element (--selector) is clicked through the page driver, and the download is watched until it ends
  (120 s, then "still downloading" with the bytes so far); a click that starts nothing in 10 s fails and disarms.
- out_path(): --path must be inside the worktree (the caller's folder when there is none) by kolux file's own rule
  (file_cli::inside: "outside", "not_a_file"); the folder is made; the name is made safe and a taken name gets a
  number (browser_downloads::place), so nothing is overwritten. Without --path a capture goes to the app data
  folder's captures/ as page-<n>-<command>-<unix seconds>.<png|jpg|pdf>.
- src-tauri/src/browser_downloads.rs: arm / disarm / take_armed / state_of; requested() uses an armed path first,
  so the existing safe-download rules (registry row, progress, finished notice, tab-close cancel) still apply.
- src-tauri/src/browser.rs: Act::DevTools and Act::Pdf behind the existing driver hook, devtools(), print_pdf(),
  captures_dir(); src-tauri/src/browser_engine.rs: the DevTools and PrintToPdf glue (main thread start, answer
  waited for on the command line's thread, 30 s).
- evidence/browser-T-251-cli.rs.patch regenerated: help lines for --path and what the capture, pdf and download
  verbs do now; evidence/browser-T-251-local_cli.rs.patch regenerated: the agent-context summaries no longer say
