VIEW-109
- Shortcut labels use the layout's characters: src/terminal/keyLayout.ts reads the Keyboard Map API
  (navigator.keyboard.getLayoutMap) at start, on "layoutchange" and on window focus (the Windows equivalent of
  "follows layout changes on Mac"), and labels a punctuation chord key with the character the layout prints at that
  physical position (German: Ctrl+/ reads Ctrl+-, the minus key reads ß, semicolon reads Ö). Letter and digit chords
  already fire on the key that types them as well as on the US position (keymap.ts keyMatches), so their labels stay.
  Wiring: evidence/core-T-253-keymap.ts.patch (keyLabel goes through layoutKeyLabel).
- Input method composing: shellKeys.routeKey already hands every composing key (isComposing / 229) to the terminal's
  composition, so Enter that confirms a candidate never sends; the window's own chord handler now does the same so a
  shortcut chord (the palette chord included) goes to the input method while composing:
  evidence/core-T-253-App.tsx.patch (one guard line in the global onKey).
- Extended keys reach programs: Shift+Enter in agent panes (TERM-080) and, for programs on the enhanced protocol, the
  T-306 encoder (kittyKeys.ts). The protocol is used only when the program asks (so it stays off on the native Windows
  console unless the agent needs it) and resets when the program exits.
- Option as Alt: built for macOS by the input settings (optionIsMeta, automatic by layout). Left and right Option
  tracked apart is Mac-only; the Windows equivalent is built: right Alt as AltGr types its character and is never sent
  as Ctrl+Alt (kittyKeys altGraph).
VIEW-110
- Copy limit: copy.ts COPY_CAP (10 MiB of text). A copy over it writes nothing, keeps the selection and says
  "The selection is too big to copy (12.0 MB of text; the limit is 10.0 MB). Select less and copy again." No crash.
  Programs' OSC 52 writes keep their own cap and notice (osc52.ts PAYLOAD_CAP).
- Programs copy to the clipboard by default (OSC 52 on). An off saved by an older build is overridden once: it reads
  as on until the user turns it off on the current settings page, which saves terminalOsc52Chosen with the value
  (inputPrefs.ts osc52On / osc52Save; page wiring evidence/core-T-253-InputCards.tsx.patch).
