Decisions (defaults, for Txais to confirm in the bug-fix phase)
  - Quiet = idle 7 days or more (newest of last commit time and folder change time), or merged into the project's base
    (saved base, else the default branch), or the folder is gone. 7 days is my default; no card names a number.
  - "Show every workspace" means every Kolux-made workspace; one Kolux did not make is never listed (T-113-b rule wins).
  - Trash folder name is `.kolux-trash-<pid>-<n>-<name>` beside the workspace; the sweep also takes the older
    `.kolux-trash-<name>` and `<name>.kolux-trash` forms. Only directories (or links, unlinked not followed) with those names.
  - Kept branches are only offered for workspaces recorded as opened on an existing branch (PROJ-030 origin record).
  - In unit tests the trash is emptied inline (cfg!(test)) so tests that delete their own temp folders do not race a second
    deleter; the threaded path is covered by proj074_a_deleted_workspace_goes_through_a_hidden_trash_and_can_be_moved_back.
