WHAT WAS BUILT
- src-tauri/src/shell_marks.rs (new, lane-owned): shell wrappers that make zsh, bash, fish and PowerShell print the
  FinalTerm/VS Code shell-integration marks (OSC 133;A before each prompt, 133;C at a command start, 133;D;<exit> at the
  end) while the user's own files still run first: zsh via a ZDOTDIR shim (.zshenv/.zprofile/.zshrc/.zlogin each source the
  user's file, KOLUX_USER_ZDOTDIR keeps the original), bash via --rcfile with login emulation (KOLUX_BASH_LOGIN=1 reads
  /etc/profile and the first of .bash_profile/.bash_login/.profile; 0 reads .bashrc) and a guarded DEBUG trap, fish via
  --init-command (runs after config.fish), PowerShell via -NoExit -EncodedCommand (UTF-16LE base64, the encoded route
  the card names; the hook wraps the prompt function and runs the startup command once). `apply` rewrites a
  CommandBuilder in place; `write_files` writes the shims only when their text changed. `typed_as_is` decides when a
  command is short/plain enough to type; longer or quoted ones go whole. ACCT-065: `unix_shell_chain` (bare name passes
  through alone; a missing full path falls back to zsh, bash, sh from /bin, /usr/bin, /usr/local/bin, /opt/homebrew/bin,
  login shell first; never a path twice) and `none_started` (lists every shell tried; pty::spawn_first already does this).
- src/terminal/shellMarks.ts (new, lane-owned) + shellMarks.test.ts: split-safe OSC scanner (133 A/C/D, 0/2 titles, BEL and
  ST terminators, abandons an OSC cut by another escape, 4 KiB cap), `Gate` (holds pre-prompt output, shows it at the
  mark, on exit, or after READY_WAIT_MS 4 s; 1 MiB cap keeping the newest), `Startup` (fires exactly once at the first
  prompt mark; quiet-timer fallback only for shells without hooks; `exited()` says when the command never went),
  `startupText` (typed + Enter, or one bracketed paste + Enter for long/quoted/multi-line text), `printsMarks`.
  Also the TERM-058 identity helpers used by T-119-c (reduceIdentity, shownAgent, tabAgent, followedTitle).

DECISIONS (for Txais, defaults taken)
- D1: ready marker = OSC 133 (FinalTerm protocol, as VS Code, WezTerm, Kitty, iTerm2 read it), not a Kolux-private
  sequence, so other terminals' shell-integration docs apply and agents that already emit it are understood.
- D2: long/quoted startup commands for zsh/bash/fish go through the PTY as one bracketed paste followed by Enter (the
  shell's stdin; the line editor takes it as a unit). PowerShell's startup can ride the encoded command; the pane also
  pastes it, since today the startup text lives only in the webview (Pane.typed), not in the spawn call.
- D3: the pane waits at most 4 s for the first prompt mark; a shell without hooks (sh, cmd, wsl) is not held at all.
- D4: PowerShell gets prompt marks (D;exit then A) but no command-start mark (no preexec hook in PowerShell); agent
  identity in a PowerShell pane comes from titles alone.

BLOCKER (partial): the macOS/Linux fallback (ACCT-065) and the zsh/bash/fish wrappers can only be run on those systems.
  Logic is unit-tested with an injected "runnable" check; the live acceptance boxes need a Mac/Linux build (DT-C41).
