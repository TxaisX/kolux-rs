WHAT NOW EXISTS
- src-tauri/src/session_files.rs (declared in sessions.rs as sessions::files, so lib.rs gets three handler lines only):
  session_delete(agent, id), session_reveal(agent, id), session_open(agent, id). The window names a session by agent and id;
  the paths come from the session roots (sessions::list::find_session), never from the window.
  - confined(root, path): refuses a `..` component, a link, the sessions folder itself and anything whose real path is not
    strictly below the real sessions folder (a junction or symlink leading out is caught by the canonical check).
  - sessions folder per agent: Claude <config>/projects; Codex <home>/sessions and <home>/archived_sessions.
  - delete: the transcript plus, for Claude, the folder named after the session id (sub-agent runs, tool output). Every path is
    checked before the first one is removed, so one refused path deletes nothing. Neighbouring sessions are not touched.
    Removal is for good (no trash), which is why the row asks first.
  - reveal: links::reveal (explorer /select, open -R, xdg-open of the folder); open: artifacts::system_open. No new opener.
- src/sessions/files.ts (runFileAction: session_reveal / session_open / session_delete), SessionFiles.tsx (Show file, Open file,
  Delete... which turns the row's buttons into "Delete this session's files? This cannot be undone." with Delete and Keep),
  mounted in AgentsPanel.tsx's row actions; a delete drops the row at once and rescans.

LIVE PROOF PENDING (batched)
1. Open the Agents tab with a Claude session listed. Click Show file: the file manager opens with the .jsonl selected.
2. Click Open file: the system's program for .jsonl opens it.
3. Click Delete...: the row's buttons turn into the warning with Delete and Keep. Keep restores the buttons, nothing removed.
4. Delete...: Delete: the row disappears, the note reads "Session deleted (N items removed)." and the file (and the folder of
   the same name) is gone from <config>/projects/<folder>/. Other sessions in that folder are still listed after Refresh.
5. Mac and Linux: Show file selects the file (Mac) or opens the folder (Linux); same opener as a file link.

- Delete-only name check (session_files.rs safe_delete_id): letters, digits, _ . - only, no ':' and no trailing '.', so `a:b`, `C:x`, `abc.` never reach the Claude folder lookup.
