chat wave 2, T-080 (VIEW-020): hand one agent's result to another agent

What changes for the user (once evidence/chat-FIX-2-App.patch is applied):
  1. On the Agents screen, a chat session whose turn is over (the agent is not mid-turn) shows a
     small "Send result to..." menu in the chat's header, left of the Show terminal switch, when
     at least one other session in the window can show chat.
  2. The menu lists the other chat-capable sessions (plain shells and the source itself are not
     listed), the last viewed first, then the never-viewed ones in pane order, at most 5.
  3. Picking one puts the source's last reply into that session's composer draft, after whatever
     was already typed there (a blank line between), and the screen moves to that session, whose
     composer opens with the text. Nothing is sent; the user reviews and presses Send.
  4. A reply line that is a whole file path with a space in it (C:\..., ~/..., \\server\..., or
     /a/b...) arrives quoted, so the target agent reads it as one path. Sentences, slash commands,
     already-quoted paths and paths without spaces are untouched.
