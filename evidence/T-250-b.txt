CLI-002 (grammar of not-yet-built commands), CLI-022 (file open, diff, open-changed), CLI-008 (register the command system-wide)

What the user can now do
  kolux file open <path>, kolux file diff <path> [--staged], kolux file open-changed [--mode diff|edit|both]
  from any terminal: each tells the running app to open the editor tab or the diff tab and says what it opened
  and what it skipped. Settings can call three new app commands (cli_register_state, cli_register,
  cli_unregister) to add or take away the kolux command for the whole system (Windows PATH, Linux launcher).

LIVE PROOF PENDING (batched; needs the running app, not run here)
  1. Start the app, run kolux-dev file open src/App.tsx from inside a repo folder: an editor tab opens beside the focused pane and the window comes forward.
  2. In a worktree that is not the open one, run kolux-dev file diff <changed file> --worktree name:<w>: the window switches to that worktree and shows the diff tab.
  3. Change two files and delete one, run kolux-dev file open-changed --mode both: diff tabs for all, editing tabs for the existing ones, one skipped line for the deleted file.
  4. Settings (after the registration UI exists): register, open a fresh terminal, run kolux-dev --version; unregister and check the PATH entry is gone. Do this only in a throwaway Windows user, never over the real PATH while testing.
