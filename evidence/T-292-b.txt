RULES AS BUILT
- Item shows only while an update runs or has just reported: Updating N skills, Stopping the skill update, Updated N skills
  (green check, clears 4 s after it was reported, or 4 s after the dialog that was showing it closes), Skill update failed
  (red, stays until clicked). A stopped run or a start error counts as failed.
- Click: reopens the update dialog (brings the Skills page up first when another screen is showing); a failure is also
  acknowledged (item gone, the app's own record cleared) and the dialog still shows its results.
- Pill: changed locally / unrecorded / any kept copy shows Review, never Update.

6. Make an update fail (no Node.js on PATH in the scratch profile): the red "Skill update failed" stays for minutes; click it:
   the Skills page opens (from any screen) with the dialog showing the reason; the item is gone.
