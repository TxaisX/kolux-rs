T-320 · SKILL-020 Skill row actions and skill details
Lane: skills · branch lane/skills · base 950ba36 · after T-180 f304dc1 · 2026-10-14

WHAT THE USER CAN NOW DO
Every row on the Skills page has an actions button (three dots, "Skill actions") with View details,
Reveal file, Copy path and Delete. Copy path puts the skill file's path on the clipboard and a short
"Path copied" toast confirms it. Reveal file opens the file manager with SKILL.md selected. Delete goes
through the same confirmation as the bulk delete (T-180). View details opens a dialog with "Used by:" (the
AIs that see the skill), "Last updated:", the path as selectable text, and Copy path, Reveal file and
Delete buttons. Built-in skills have no file, so Reveal and Copy are disabled with the reason; built-in
and plugin skills show Delete disabled with the bulk delete's reason.
