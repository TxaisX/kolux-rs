WHAT THE USER GETS (once both patches land)
- Keep-awake in Agent mode counts a working pane only while its terminal is still running. A pane
  that reported "working" with no terminal behind it (a script printing the in-band status in a
  hookless pane) or a late hook that arrives after its terminal ended no longer holds the computer
  awake for up to 30 minutes.
- A refused sleep hold (systemd-inhibit with no system bus, say) is asked for again once a minute
  instead of being started anew every 5 s; it is asked at once when keep-awake is wanted anew.
- Settings > Agents, keep-awake: the On help now warns that on a Modern Standby laptop a constant hold
  drains the battery even with the lid closed (Microsoft's SetThreadExecutionState guidance); the
  Agent help says plainly that an agent started inside a shell pane that stops without saying so
  counts for at most 30 minutes after its last word.
- Honesty fix (FS 2): "a crashed agent releases the hold" is now worded as "the agent that is the
  pane's own program exits or crashes" in the status patch comment and in launch-FIX-1.txt. An agent
  typed into a shell pane ends with the shell, not with the agent, so it stops counting only when it
  reports done or after the 30-minute window.
