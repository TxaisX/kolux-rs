The pane's Claude Code read the user's real config folder (its /hooks screen listed the user's own
hooks), so its hooks never reached the lane app. The receipt and the wait states were proved by
posting hook reports for term-2 to the app's hook endpoint by hand, as the hook script does:

$ (sleep 1.2; POST /claude {"hook_event_name":"UserPromptSubmit",...}) & \
  $K terminal send --terminal term-2 --text "Reply with only the word ping" --enter --wait-submit 4 --json
    "agent": "claude",
    "prompt": true,
    "receipt": "turn_began",
exit 0
