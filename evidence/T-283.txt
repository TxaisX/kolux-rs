BROW-010 (pages after wake)
- src-tauri/src/browser_wake.rs (new): one watcher thread for the whole app (started on the first
  page open) looks at the wall clock every 5 s; a jump of more than one tick plus 25 s means the
  computer slept, and it sends one signal, "browser-wake", that every browser pane hears.
- src/browser/loadState.ts: a new "woke" event. A page showing the failed/crashed overlay is
  reloaded with a fresh recovery allowance; any other page keeps being probed (T-074) with a fresh
  automatic reload, so a page sleep took is rebuilt instead of showing the overlay; a blank tab
  stays blank. Each pane acts on its own, so one page that cannot recover does not stop the others.
- src/browser/BrowserPane.tsx: listens for "browser-wake" and feeds "woke".

BROW-043 (leftover helpers)
- src-tauri/src/browser_helpers.rs (new). Selection is never by program name alone:
  - each page's engine browser process (BrowserProcessId from the page's controller) is recorded
    with the system's start moment, its program file and the owning run (this app's process id and
    start moment) in browser-helpers.json in the profile folder;
  - at start (lib.rs setup through the patch, or the first page open), on a thread of its own: a
    record is closed only when its run is gone (owner not running, or the owner id now belongs to a
    later process) AND the recorded process still runs with the same start moment and program file
    name; this run's records and those of another live run are left alone; a helper this run
    already took over is never closed; each close goes through procs::kill_tree and one failure
    does not stop the rest; a listing that fails reads as "not running" and closes nothing;
  - at quit (RunEvent::Exit through the patch): this run's helpers that still run as recorded are
    stopped;
  - KOLUX_RS_NO_HELPER_SWEEP switches the start-up sweep off only for 1, true, yes or on.
- Rule "helper idle time-outs are longer than command time-outs": no helper in this tree has an idle
  time-out of its own (the engine's processes live as long as their pages); nothing to set.

Patch (shared file, for the resolver; applies with -C1 after the earlier browser lib.rs patches)
  evidence/browser-T-283-lib.rs.patch: setup calls browser::helpers::sweep_at_start(&dir) after
  diag::set_dir; RunEvent::Exit calls browser::helpers::stop_all() after final_save::begin().
