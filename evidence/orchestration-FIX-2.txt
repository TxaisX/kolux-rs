WHAT CHANGED
1  The "remember an open prompt on exit, forget on start" rule is now three pure functions in
   src/inbox/exitedPrompt.ts: onRunning (start forgets; exit keeps only permission or waiting,
   replaces an old one when the program ended another way, and changes nothing when no hook state
   is left because the exit callback can run twice), onClose (a closed pane's prompt goes), and
   inboxOverlay (the sources the Inbox reads; also drops the entry once the pane runs again, a
   fresh hook state arrived for it, or the pane is no longer a source).
2  Pruning: onClose is called from dropPanes, and inboxOverlay prunes on every render, so entries
   cannot pile up for the life of the window. A late hook event after the exit wins and clears the
   remembered prompt for good.
3  Floor: INDENT_LIMIT = 5 and indent(depth) in timeline.ts; FloorView uses it for the shared name
   column (110 + 14 * min(depth, 5) = at most 180px) and the per-lane padding. data-depth keeps the
   true depth.
