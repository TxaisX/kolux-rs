T-444 (council C2 Q5): the explorer re-reads its tree when the window gets the focus back, when the
panel is shown again, or when the workspace changes.
Built 2026-10-13 on lane look, dev app port 1426, scratch profile; scratch git repo registered as
project "repo" (notes.md, src/a.txt), its master workspace in front, the explorer open with src
unfolded. Every file below was made from a shell outside the app (printf > file).

What changed: src/editor/Explorer.tsx. While the panel is shown, a window "focus" listener reads
the root and every open folder again (dir_list) into the same tree, so open folders, selection and
scroll stay; showing the panel does the same read once. The explorer is not remounted for this.
A workspace switch already mounts that worktree's own explorer, which reads its tree.

1. Real window focus (acceptance). A focus/blur logger was put on the page; the window was away
   (document.hasFocus() = false), then refocus-proof.md was made outside the app:
     away:  rows "src, a.txt, b.txt, notes.md, outside.md, outside2.md, outside3.md", hasFocus=false
   the window got the focus back (Page.bringToFront over CDP; no event was sent by script):
     back:  rows "... outside3.md, refocus-proof.md", hasFocus=true,
            events logged: focus, blur, focus                     <- it appears
   Earlier in the same run b.txt (inside the open src folder), outside.md and outside2.md had
   appeared the same way after the window came back from other windows.
2. Panel shown again: refocus-check.md, refocus-check2.md, shown-check.md made outside, then
   Source Control tab, then Explorer tab:
     rows "src, a.txt, b.txt, notes.md, outside.md, outside2.md, outside3.md, refocus-check.md,
           refocus-check2.md, refocus-proof.md, shown-check.md"     <- all three appear, src still open
3. Focus event on the window (the same event the listener takes) after src/c.txt was made outside:
     before: "src, a.txt, b.txt, notes.md, ..."
     after:  "src, a.txt, b.txt, c.txt, notes.md, ..."               <- appears inside the open folder
   screenshot: evidence/explorer-refocus.png (1920 wide, dark)
4. Workspace change: ws-check.md made outside, demo-app's main picked, then repo's master again:
     rows "src, notes.md, ..., shown-check.md, ws-check.md"          <- appears (that worktree's own
     explorer, folders folded as before)

Note: hiding or minimising the app window does not blur the page in WebView2 (hasFocus stays true),
so the focus read happens when the window really loses the focus to another app and gets it back.
Not here: a file watcher (live refresh while the window stays focused) is T-236's.
