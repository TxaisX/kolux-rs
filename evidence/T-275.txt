T-275 (STAT-031 Agents that are gone stop reporting), lane/watch, 2026-10-19, Claude Sonnet 5.5. Routing v3: unit-proven, live proof pending (batched).

What is built (own files, committed): src/status/gone.ts and src/status/gone.test.ts.
- Rule 1 (a working or waiting row whose process is certainly dead is retired): deadKeys() finds agent panes whose hook state is
  working / queued / waiting / permission / blocked while their program is certainly down (running is exactly false; unknown is not
  certain). retire() drops that hook state (the row falls back to the program-ended guess, "done"), clears the tool / question /
  plan / monitoring lines and the sub-agent list, and keeps how the turn stopped, the last reply and the file written. The
  pane itself, and with it its resume identity (Pane.session), is never touched.
- Rule 2 (a closed tab's late events are ignored until Kolux quits; other tabs carry on): noteClosed() puts every key that
  disappears from the pane list on a window-lifetime ledger; admit() refuses a closed key and a key no pane has. Restart in place
  gives a new key (restartPane), so the pane that replaces an old one starts clean.
- Rule 3 (a retired pane returns only on a genuine new turn): admit() lets a retired pane back only for a fresh start, or a working
  report while the program is up again; the old process's late Stop or ask is dropped.
- useGone() is the one hook that runs these (ledger sync, closed-tab cleanup of hook / turn / crew, retirement).
- The Rust side already did its half before this task: status::terminal_ended retires the session of an ended terminal and drops
  hooks still in flight from it (T-563, hooks FIX-4 / FIX-5); nothing changed there.
