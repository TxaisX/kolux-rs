What changed, per item
1. Profile paths (FIX-BEFORE 1): PROFILE, QUOTED_PROFILE and PROFILE_LINE are case-insensitive and also know Git Bash /c/Users/,
   WSL /mnt/c/Users/ (and /cygdrive/c/), //wsl$/<distro>/home/, \\wsl$\, \\wsl.localhost\<distro>\home\ and the same behind \\?\.
   A user name with a space is masked whole in each spelling, bare, in quotes and in backticks. The web-address guard stays green
   (https://example.org/home/page, https://example.org/Users/list, http://c/Users and https://wsl.localhost/home/a are left alone;
   the // form of WSL needs no colon in front of it).
2. Long paths (FIX-BEFORE 2): `\\?\`, `\\.\` and `\\?\UNC\` are recognised before the path rules; the UNC host and share are then masked like any
   UNC path (`\\?\UNC\fileserver\home$\jane\x`, `\\?\UNC\fileserver\Users\Jane Doe\x`, `\\?\C:\Users\jane\x.txt`, `\\?\D:\work\client\a.ts`).
   evidence/feedback-FIX-1.txt:56 said the `\\?\C:\Users` prefix was not covered; that line is corrected in place.
3. Secret shapes (FIX-SOON 1): Slack and Discord webhook addresses, hf_ tokens, AccountKey=, sig=, MYSQL_PWD, --pass,
   "pass is ...", backtick-quoted values after a name, and `Authorization: token X` (the scheme word stays, the token goes).
   Look-alikes stay: the sig file, a bypass is fine, he passed is odd, --pass-through, hooks.slack.com and discord.com/api/docs with no token, hf_trainer.
4. Speed (FIX-SOON 2): the name rule is found by its keyword alone with at most 128 more name characters (nothing before it is rescanned),
   the flag rule allows at most 6 dash words, the quoted profile search stops after 2000 characters (a longer or unclosed path is masked
   to the end of its line by PROFILE_LINE), and the trailing marks of a path are found by walking back from its end (a loop, not a regex).
   13 timing tests, one per shape, each asserts under 800 ms; they fail on the old code (above).
5. Clipboard (FIX-SOON 3): the opt-in run was redone with --ignored --test-threads=1 --nocapture and its output kept (above), and a skip
   panics when CLIPBOARD_TESTS_MUST_RUN is set.
6. PLAN (FIX-SOON 4): the T-249 line now claims only what is built (the feedback message box, the file-list and verified-text copy
   commands, the feedback-box half of PROJ 089); no "images", no "also passes PROJ-089"; picture paste, the crash half, the CLI cards and
   every caller stay in T-249-b.
