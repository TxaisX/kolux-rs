kolux file diff

Usage: kolux file diff <path> [--staged] [--worktree <selector>] [--json]

Open a workspace file diff in the Kolux editor

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --path <path>          Path argument for the command
  --staged               Open staged source-control changes
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current

Notes:
  Diffs default to unstaged changes. Pass --staged to open the staged source-control diff.
  The path may be relative to the selected worktree or an absolute path inside that worktree.

Examples:
  $ kolux file diff src/App.tsx
  $ kolux file diff --path package.json --staged --worktree branch:feature
