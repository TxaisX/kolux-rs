kolux project setup-delete

Usage: kolux project setup-delete --setup <setup-id> [--json]

Remove a project host setup

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --setup run|skip|inherit Setup policy for repo-defined setup hooks

Notes:
  Independent setups are removed directly.
  Repo-backed setups remove the registered repo compatibility record.

Examples:
  $ kolux project setup-delete --setup github:TxaisX/kolux::gpu --json
