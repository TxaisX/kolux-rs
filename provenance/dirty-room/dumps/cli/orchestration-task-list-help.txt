kolux orchestration task-list

Usage: kolux orchestration task-list [--status <status>] [--ready] [--brief] [--run <run_id>] [--from <handle>] [--json]

List orchestration tasks

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --status
  --ready
  --brief
  --run
  --from

Notes:
