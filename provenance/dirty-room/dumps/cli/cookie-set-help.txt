kolux cookie set

Usage: kolux cookie set --name <n> --value <v> [--domain <d>] [--path <p>] [--secure] [--httpOnly] [--sameSite <s>] [--expires <epoch>] [--worktree <selector>] [--json]

Set a cookie

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --name <name>          Name for the new worktree or automation
  --value <text>         Value to fill or select
  --domain
  --path <path>          Path argument for the command
  --secure
  --httpOnly
  --sameSite
  --expires
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current
  --page <id>            Stable browser page id from `kolux tab list --json`
