kolux environment add

Usage: kolux environment add --name <name> --pairing-code <code> [--json]

Save a remote Kolux runtime environment from a pairing code

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --name <name>          Name for the new worktree or automation
  --page <id>            Stable browser page id from `kolux tab list --json`

Examples:
  $ kolux environment add --name work-laptop --pairing-code kolux://pair?code=...
