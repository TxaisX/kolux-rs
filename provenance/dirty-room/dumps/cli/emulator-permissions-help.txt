kolux emulator permissions

Usage: kolux emulator permissions <grant|revoke> <package> <permission> [--device <id>] [--json]
       kolux emulator permissions reset [--device <id>] [--json]

Grant/revoke an Android runtime permission, or reset all runtime grants

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --device
  --emulator
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current
  --op
  --package
  --permission
