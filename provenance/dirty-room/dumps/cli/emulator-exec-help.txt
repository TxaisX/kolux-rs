kolux emulator exec

Usage: kolux emulator exec --command <cmd> [--device <id>] [--worktree <selector>] [--json]

Raw passthrough (e.g. kolux emulator exec --command "tap 0.5 0.7" or "ca-debug blended on")

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --command <text>       Command to run in the terminal on startup
  --device
  --emulator
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current
