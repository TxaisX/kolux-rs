kolux computer drag

Usage: kolux computer drag --app <app> (--from-element-index <n> --to-element-index <n> | --from-x <x> --from-y <y> --to-x <x> --to-y <y>) [--window-id <id> | --window-index <n>] [--restore-window] [--no-screenshot] [--json]

Drag between app elements or window coordinates

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current
  --session <id>        Snapshot namespace for a related computer-use workflow
  --app <app>            App name, bundle ID, or pid:N
  --window-id <id>      Target a window id from list-windows
  --window-index <n>   Target a window index from list-windows
  --restore-window     Bring the target app/window forward before the operation
  --no-screenshot       Skip screenshot capture after the operation
  --from-element-index <n> Source element index from get-app-state
  --to-element-index <n> Destination element index from get-app-state
  --from-x <x>           Source window-local x coordinate
  --from-y <y>           Source window-local y coordinate
  --to-x <x>             Destination window-local x coordinate
  --to-y <y>             Destination window-local y coordinate
