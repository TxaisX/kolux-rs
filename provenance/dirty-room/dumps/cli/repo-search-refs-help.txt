kolux repo search-refs

Usage: kolux repo search-refs --repo <selector> --query <text> [--limit <n>] [--json]

Search branch/tag refs within a repo

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --repo <selector>      Repo selector such as id:<id>, name:<name>, or path:<path>
  --query <text>        Search text for matching refs
  --limit <n>            Maximum number of rows to return
