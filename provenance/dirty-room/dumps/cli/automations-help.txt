kolux automations

Usage: kolux automations <command> [options]

Commands:
  list               List scheduled Kolux automations
  show               Show one Kolux automation
  create             Create a scheduled Kolux automation
  edit               Edit a Kolux automation
  remove             Remove a Kolux automation and its run history
  run                Run a Kolux automation now
  runs               List automation run history

Run `kolux automations <command> --help` for command-specific usage.
