kolux linear project list

Usage: kolux linear project list [--query <text>] [--limit <n>] [--workspace <id>|all] [--json]

List connected Linear projects

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --query <text>        Search text for matching refs
  --limit <n>            Maximum number of rows to return
  --workspace <id>      Connected Linear workspace id

Examples:
  $ kolux linear project list --query launch --json
  $ kolux linear project list --workspace all --json
