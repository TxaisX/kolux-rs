kolux linear attach

Usage: kolux linear attach [<id>] [--current] --url <url> [--title <title>] [--write-id <uuid>] [--workspace <id>] [--json]

Attach a link to a Linear issue

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --current              Use the current Kolux worktree linked Linear issue
  --url <url>           Absolute http(s) link to attach
  --title <text>        Attachment title
  --write-id <uuid>     Retry id from linear_write_unconfirmed
  --workspace <id>      Connected Linear workspace id
  --id <id>             Identifier for a target item or permission

Examples:
  $ kolux linear attach ENG-123 --url https://example.com/review/123 --title "PR/MR link"
  $ kolux linear attach --current --url https://example.com/review/123 --json
