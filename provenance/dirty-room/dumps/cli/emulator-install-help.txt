kolux emulator install

Usage: kolux emulator install <apkPath> [--reinstall] [--device <id>] [--json]

Install an APK onto the target Android device

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --device
  --emulator
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current
  --path <path>          Path argument for the command
  --reinstall
