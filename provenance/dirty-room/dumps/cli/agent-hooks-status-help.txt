kolux agent hooks status

Usage: kolux agent hooks status [--json]

Show whether Kolux-managed agent status hooks are enabled

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --page <id>            Stable browser page id from `kolux tab list --json`

Examples:
  $ kolux agent hooks status
  $ kolux agent hooks status --json
