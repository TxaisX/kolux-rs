kolux terminal split

Usage: kolux terminal split [--terminal <handle>] [--direction horizontal|vertical] [--command <text>] [--json]

Split an existing terminal pane

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --terminal <handle>  Runtime-issued terminal handle
  --direction <dir>      Direction: up|down|left|right for scroll, horizontal|vertical for split
  --command <text>       Command to run in the terminal on startup

Examples:
  $ kolux terminal split --terminal term_abc123 --direction horizontal --json
  $ kolux terminal split --terminal term_abc123 --command "codex"
