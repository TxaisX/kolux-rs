kolux account list

Usage: kolux account list [--json]

List managed Claude and Codex accounts on this Kolux host

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment

Notes:
  Lists the accounts on this machine. `--environment` / `--pairing-code` are rejected rather than ignored; run it on the host whose accounts you want to see.

Examples:
  $ kolux account list
