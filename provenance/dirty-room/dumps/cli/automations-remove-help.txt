kolux automations remove

Usage: kolux automations remove <id> [--json]

Remove a Kolux automation and its run history

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --id <id>             Identifier for a target item or permission

Examples:
  $ kolux automations remove 2f9e...
  $ kolux automations remove --id 2f9e... --json
