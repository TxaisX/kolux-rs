kolux project

Usage: kolux project <command> [options]

Commands:
  list               List durable projects known to Kolux
  setups             List project host setups
  setup-existing-folder Make a project available on a host by importing an existing folder
  setup-clone        Make a project available on a host by cloning a repository
  setup-create       Create independent project host setup metadata
  setup-update       Update project host setup metadata
  setup-delete       Remove a project host setup

Run `kolux project <command> --help` for command-specific usage.
