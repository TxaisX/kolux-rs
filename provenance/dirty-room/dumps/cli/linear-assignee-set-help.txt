kolux linear assignee set

Usage: kolux linear assignee set [<id>] [--current] (--me | --to-id <userId>) [--workspace <id>] [--json]

Assign a Linear issue

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --current              Use the current Kolux worktree linked Linear issue
  --me
  --to-id
  --workspace <id>      Connected Linear workspace id
  --id <id>             Identifier for a target item or permission

Examples:
  $ kolux linear assignee set --current --me --json
