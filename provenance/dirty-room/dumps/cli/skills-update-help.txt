kolux skills update

Usage: kolux skills update [--skill <name>]... [--all] [--local] [--dry-run] [--json]

Update already-installed Kolux skills via the community skills CLI

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --skill <name>         Bundled skill to act on; repeat for several
  --all
  --local                Target the current project instead of the global install
  --dry-run

Notes:
  Reads the bundled skill registry locally without contacting the Kolux runtime.
  Resolves to the same `npx skills update <names...>` command used by Kolux Settings, plus the non-interactive flags an unattended host needs (`npx --yes` and `-y`), then runs it and forwards its output and exit code.
  Updates the global install (all projects, adds --global) by default. Use --local to update the current project instead.
  Only refreshes skills that are already installed; use `kolux skills install` first.
  Use --dry-run to print the resolved command without running it.
  With --json, the skill listing and --dry-run emit JSON; a real update streams npx's own non-JSON output live and rejects --json.
  Omit --skill and --all to list updatable skill names.
  Intended for headless hosts (SSH, containers, CI) with no desktop Settings UI to copy the update command from.

Examples:
  $ kolux skills update
  $ kolux skills update --skill kolux-cli --skill orchestration
  $ kolux skills update --skill kolux-cli --local
  $ kolux skills update --all --dry-run
