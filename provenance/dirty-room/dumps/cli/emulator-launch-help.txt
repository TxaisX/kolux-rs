kolux emulator launch

Usage: kolux emulator launch <package> [--activity <name>] [--device <id>] [--json]

Launch an Android app by package (and optional activity)

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --device
  --emulator
  --worktree <selector>  Worktree selector such as identity:<identity>, id:<repo-id>::<path>, name:<displayName>, branch:<branch>, issue:<number>, path:<path>, or active/current
  --package
  --activity             Include issue field-change history
