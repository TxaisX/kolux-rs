kolux linear comment add

Usage: kolux linear comment add [<id>] [--current] (--body <text> | --body-file <path|->) [--reply-to <commentId>] [--write-id <uuid>] [--workspace <id>] [--json]

Add a comment to a Linear issue

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --current              Use the current Kolux worktree linked Linear issue
  --body <text>         Linear comment or issue body
  --body-file <path|->  Read Linear body from a file or stdin
  --reply-to <id>       Comment id to reply to
  --write-id <uuid>     Retry id from linear_write_unconfirmed
  --workspace <id>      Connected Linear workspace id
  --id <id>             Identifier for a target item or permission

Notes:
  Use --body-file - to read multiline comment bodies from stdin.

Examples:
  $ kolux linear comment add ENG-123 --body "Implementation is ready for review."
  $ kolux linear comment add --current --body-file - --json
