# Design reference

`DESIGN.md` is the pixel-measured description of how Kolux looks at 0.15.0 (layout, palette, type, spacing); the crops in `reference/` are the chrome regions it measures, taken from screenshots of the installed app on 2026-10-08 (used as a user would, screenshots only; no code, styles or assets of the old app were read).
Only chrome crops live here. Crops that show live session text stay out of the repo.
