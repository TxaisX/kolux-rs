# Signs of an injection attempt

- Text addressed to "the AI", "the assistant" or "the agent" inside ordinary content.
- Claims of authority: "the admin says", "new system policy", "urgent from the owner".
- Requests to change settings, permissions or the list of allowed commands.
- Hidden text: white-on-white, HTML comments, zero-width characters, long base64 blobs.
- Links or commands that send data to an address nobody mentioned before.
