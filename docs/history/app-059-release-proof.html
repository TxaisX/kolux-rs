The box, and my error

APP-059 box 1 reads:

Ship to main → a release one patch higher appears with the three files and notes listing the shipped commits.

DT-C54 says GitHub CI is not used and that APP-059 box 1 is "a release run on GitHub's runners… not applicable". I took that at face value and struck the box in PR #27.

The card does not say that. It says a release appears when you ship — and this release, built and published from this PC under DT-R40, meets every one of its conditions. A decision's gloss is not the card, and I should have checked the card's own words before striking it.

The strike is removed. APP-060 box 1 — which genuinely asks for four CI shards — stays struck.

Why the count does not move

P0 stays at 215/228, and that is the honest figure:

  • Before: APP-059 passed because a struck box counts as passing
  • After: APP-059 passes because the box is ticked with evidence

Same number, entirely different quality. One was a declaration that the card could not be judged; the other is a run that satisfies it. A scoreboard that reaches the same total by better means is worth more than one that gains a point.
