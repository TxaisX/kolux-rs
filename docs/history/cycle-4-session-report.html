What shipped

PR #25 — first load under the 1.5 MB bar

The coordinator had finished the work and died before committing it. Two causes, both removed:

  1. editor/buffers.ts carried CodeMirror for one undo annotation, dragging in @codemirror/view and language — a 315,352-byte chunk paid on every first frame, even for users who only ever open a terminal. The CodeMirror side moved to editor/editors.ts.
  2. The Help menu pulled in the whole guide — its steps, ring, tour catalogue and five small modules. The menu is now a button; onboarding/HelpSheet.tsx loads on first click.

Result: 1,864,072 → 1,471,768 bytes, 28,232 under the bar, across 38 chunks.

The lane had been rejected once before for silently breaking the T-603 line-ending work, so it was checked rather than trusted: isDirty still compares fileText against disk, and mixedLineEnds.test.ts gained one import line and no assertion change.

The ceiling in scripts/bundle-budget.mjs dropped 1,880,000 → 1,485,000, and its test now asserts CEILING <= 1_500_000 — so the bar can no longer be raised back over itself.

PR #26 — documentation that cannot drift

scripts/docs/build.mjs renders a self-contained HTML twin for any doc that opts in with <!-- html -->. Stylesheet inlined, nothing fetched — which matters because these pages also open inside Kolux, whose artifact viewer allows only its own origin. --check fails the build when a twin is stale.

Opt-in rather than automatic: an early version generated HTML for all 24 existing docs, which is noise, not documentation. That was reduced to a deliberate marker.

PR #27 — the scoreboard stopped counting untestable boxes

Five P0 acceptance boxes name a machine or workflow this project does not have: a GitHub-runner release, an older kolux installation that was deleted, Linux, and macOS.

DT-C54 had already declared two of them not applicable — but in prose, and plan-check only understands strikes CARD-nnn box N with confirmed by Txais YYYY-MM-DD on the same line. A decision that had been made was invisible to the score board the whole time. DT-C60 and DT-C61 record it in the form the checker reads: 210 → 215.

Deliberately left open: SAFE-004 box 3 (a product decision, DT-C59) and USAGE-021 box 3 (waits on T-547). Neither is impossible — only unfinished. A box is struck only when no code change could ever close it.

PR #28 — the live-proof harness was dead

This is the most consequential finding of the session.

scripts/prove/live-installed.mjs gated all six of its commands on isMain, which was referenced six times and never defined. Every invocation died at module load:

ReferenceError: isMain is not defined
    at scripts/prove/live-installed.mjs:194

This is the harness the entire live-proof strategy depends on — 80+ per-card scripts and every open P0 card waiting to be ticked. It could not run a single check.

Second defect found while fixing it: start and stop call closeRunning(), which closes every kolux-rs.exe window. Correct from a shell, fatal from inside a Kolux terminal, because Kolux hosts the terminal service, the service hosts the shell, and the shell hosts the proof:

powershell.exe → opencode.exe → opencode.exe → kolux-rs.exe --terminal-service

Closing the app would have ended the session running the proof. A guard now walks the parent chain and refuses with exit 2.

PR #29 — an unbounded map on a hot path

activity.rs kept a stamp for every folder ever opened, and touch() read and rewrote the whole map on each activity change — which happens on every agent state transition. Capped at the 2,000 most recently used, with deterministic tie-breaking. Ordering semantics, key format and corrupt-store handling unchanged; both existing PROJ-051 tests plus a new one pass.

What is still owed

Live proofs need an ordinary terminal

The remaining P0 cards need one run from Windows Terminal or PowerShell, not a Kolux terminal:

cd <your clone of kolux-rs>
node scripts/prove/live-installed.mjs start
node scripts/prove/live-checks.mjs b7     # BROW-008 box 2
node scripts/prove/live-installed.mjs stop

Three of the eleven provable cards already have scripts (APP-052, SET-004, STAT-001, plus b2/b4/b7 in live-checks.mjs). Eight do not: APP-025, APP-048, APP-070, BROW-008, CLI-011, EDIT-044, SESS-025, STAT-008.

0.1.3 was building and had not finished at close

node scripts/release.mjs was started against main at a1c590d0 with the checkout set explicitly:

$env:KOLUX_RELEASE_CHECKOUT="<release checkout>"
node scripts/release.mjs

The default checkout path is ~/.kolux-rs/release-checkout, which does not exist here, so a bare pnpm release fails with "no build checkout … and no --repo to clone it from". That is worth knowing: the release only works with that variable set, or from the checkout that already exists.

The Rust monoliths remain

cli.rs is still 583 KB, projects.rs 328 KB, scm.rs 298 KB. A dedicated lane was delegated to begin splitting cli.rs; that work is separate and not part of this report's merged set.
