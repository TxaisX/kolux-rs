## 9. Lessons learned

1. **The shallow clone fooled ancestry checks.** Unshallow first.
2. **`.gitignore`'s `node_modules/` doesn't match a symlink.** A builder committed a `node_modules` link, and CI's pnpm install failed. #53 fixes `.gitignore`. Until it merges, keep `/node_modules` in `.git/info/exclude`.
3. **One shared `CARGO_TARGET_DIR` for many agents means queuing on cargo's lock.** Two builders ran out of turns and lost uncommitted work (#37 round 1, T-300). Run cargo in the foreground and commit early.
4. **Disk: debug info makes each checkout's full test build about 10 GB.** Build with `CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0 CARGO_INCREMENTAL=0`.
5. **CI cancels a PR's in-progress run on a newer push.** The overall "CI result" check then shows red ("rust=cancelled"); that's not a failure.
6. **This cloud session's token cannot re-run Actions jobs** (403).
7. **Windows CI found real Windows-only test bugs** (#37 clippy, #64) that the Linux container could not see. Read every red Windows job.
8. **Several agents picked the same next DT number in parallel.** Assign numbers at integration, or check every open branch first.
