# First-day UX audit, 2026-10-25 (lane ux)

Method: dev build (`pnpm tauri dev`, debug Rust + vite), hidden off-screen window, driven over CDP from `evidence/ux-audit.mjs`; flow scripts in `evidence/ux-flow-*.mjs`; readings in `evidence/ux-readings.json`; shots in `evidence/ux-shots/`. Scratch profile and home under `G:/Temp/ux-v3/`. The machine was busy with other lanes (CPU 45-88% at each reading, ~10 GB free of 32 GB), so every time is a loaded-machine, dev-build time; a packaged build would be faster. Bars: cold start 3 s, view switch 150 ms, pane change 300 ms, echo p95 50 ms, palette open 100 ms.

### Flow 2: first run
- Welcome dialog "Get started with Kolux", 4 screens (Welcome, Connect an AI, Your work, Choose a kit). Appears 2.6 s after the sidebar on a fresh profile (sidebar 7.04 s, dialog 9.66 s).
- Escape on screen 1 opens "Skip setup?" (No, keep going / Skip); a second Escape closes that prompt and focus falls to BODY (not back into the wizard).
- Screen 2: Continue is disabled with no explanation until an agent is connected; the real way forward is the small "I'll do this later" button.
- Screen 3: "Pick a folder" closes the wizard and opens the Add project dialog; screen 4 (kit) is never reached by that path.

### Flow 3: add a project
- Add project dialog opens in 35 ms from the wizard's "Pick a folder". Its primary (focused) choice is "Copy from a web address"; "Open a folder..." is the second, small choice. Escape closes it; focus falls to BODY.
- "Open a folder..." is a native dialog (not drivable here). The typed-path route is the gear at the foot of the sidebar (title "Add a project by path, or change the workspaces folder"); it opens a panel with a path field that is NOT focused on open (focus stays on BODY).
- Typed path + Enter: project row in the sidebar in 112 ms, `main` workspace selected, a PowerShell pane opens and shows its prompt (`PS G:\...\demo-app>`). The new terminal is named "Terminal 2" (there was never a Terminal 1). A coach popup "A workspace that follows you" sits over the bottom right, covering the status bar.
- Clicks: gear, click field, paste path, Enter = 4 (native route: + button, Open a folder, pick in OS dialog, confirm).

### Flow 4: new workspace

On the second open the branch line (`branch ux/<name> · folder <path>`) was there in 52 ms. Typing a new name updates the preview in 245 ms.

- The green sidebar note "demo-app is a project (G:\...)" overlaps the "Jump to current workspace" button while the composer is open.
