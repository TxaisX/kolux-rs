# Kolux RS audit, 2026-10-30: every ponytail note

Every `ponytail:` comment (a shortcut the builder took on purpose, with its limit and upgrade path) was read against the code as it is today. For each one the auditor decided whether it is still true, how much it matters to you, and what to do: **fix now** (cheap and worth doing), **make a task** (real, needs planning), **reword the note** (update-note: the comment is out of date or wrong), **delete the note** (delete-note: the problem is already fixed) or **keep** (an honest trade-off). Notes judged fix-now or high-risk went to a second reviewer. The summary is in [the audit report](repo-audit-2026-10-30.md).

**Words used here.** Worktree: the separate folder git makes for each Kolux workspace. CI: GitHub's automatic build-and-test run. Hook: the small script an agent runs to tell Kolux its status and to ask before a risky command. npm: the Node.js package installer. cmd.exe: the old Windows command prompt. Lock: while one part of Kolux holds it, every other part that needs the same data waits.

## P1-terminal-cli: ponytail notes: terminal, PTY, CLI, processes, clipboard, ports

Of the 48 notes in batch 1, 32 are honest trade-offs to keep, 6 need rewording, 3 describe problems already fixed and can be deleted, 5 deserve a planned task and 2 should be fixed now. The serious one is pty.rs:334. On Windows, agents installed through npm (Codex, Gemini CLI, Copilot and others) are started through cmd.exe with the opening prompt on its command line. A prompt with a quoted part containing |, &amp; or &gt; can cut the prompt and run the rest as a command. Where the npm folder's path has a space (nvm-windows, or a user folder with a space), almost any opening prompt stops the agent from starting at all. The second fix-now: terminal links count text characters instead of screen cells, so after a wide character (Chinese or Japanese text, or symbols such as the green check mark agents often print) the clickable area of a file path, web address or term-N link slides left. The other real gaps are that the kolux command line serves one request at a time, so a worker start with a setup script can hold every other agent's command for minutes; that 'idle' still means 'quiet for a few seconds' although status hooks now report real states; and that the Preview button only offers servers that printed their address.
